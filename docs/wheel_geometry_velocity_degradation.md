# 26cm轮径与远距离速度接续（2026-09-17）

## 改动范围

默认入口仍是 `./run_request_0428_modular.sh`。仅默认reid_runtime配置轮周长从
0.600改为0.816814m（pi×0.26），同时供Astra预测、融合编码器位移和纵向FF使用。
不改变驱动RPM/左右符号映射，不修改旋转角速度标定、搜索、身份门控。
保留目标1.5m、P24、总上限200RPM、匹配预算80RPM和物理Depth180ms期限。

用户提供的是轮径，不是独立里程标定。换算假设驱动反馈为输出车轮RPM、无打滑；
代码从驱动speed_rpm直接归一左右符号，没有另除齿轮比。需用固定平面/卷尺位移复核。
60RPM对应0.8168m/s，仅在目标静止、车已达到该速度时，约1秒追回0.817m。
目标以0.6m/s走时净追近速度约0.217m/s，追回0.81m理论约3.74秒，不含加减速。
修正轮径不是给RPM乘1.36：ego_m_s与target_m_s→RPM都使用同一轮周长。

## 速度估计与运动授权分开

- 匹配基速模式下，已测量速度先验的固定记忆期限为350ms；非匹配预算模式保持180ms。
- 已知ROI过期/重复观测只保留有限状态，不提供PID新时间戳。未验证转动不保留距离导数，
  超过180ms的导数基线也重建；不跨未经补偿转动计算新速度。
- 新鲜、同UID、远目标、有效编码器且角速度不超过15deg/s时，预热或暂缺补偿可使用
  衰减先验（80RPM/s）。不能超过先验、之前输出；不能增加既有批准速度。
- 先验来源时间不因重复帧、桥接帧或失败尝试续期。350ms后不可使用；新鲜真正速度
  估计才建立新来源。不是旧指令可执行350ms。
- 物理Depth仍180ms过期。桥接还要求相邻观测不超过180ms，运行时要求前一个运动
  授权仍有效；不能用旧先验重启已经撤销的前进。先验到期降为同一新Depth的距离控制，
  Depth到期撤销运动。身份丢失、危险、异常深度、近距、反馈无效继续拒绝。

## 远目标正在追近不等于近距离危险

动态恢复不再仅因原始距离缩短>3cm就回退25/45RPM。新增有限路径要求：

- 原/新原始距离及控制距离都大于设定+0.30m；UID/危险/反馈/新鲜度检查保持。
- 参考间隔≤350ms，缩短≤15cm，接近速度≤1m/s。
- 缩短不超过当前实测轮速对应位移+3cm；到近距保护带的时间≥1秒。
- 仍按上一批准、实测轮速、当前请求和既有有界加速限制恢复；不能随时间自动解除限制。

桥接速度也用同一闭合一致性函数，但保留自身近距门槛和不可加速规则。
CAP307形状离线测试：2.881→2.805m/220ms，实测57.5RPM，新深度10ms，
允许52RPM量化请求通过，而不是降到24RPM；不是实车效果承诺。

`prior_remaining_ms`，与Depth剩余时间分开。现有bridge日志保留origin_ts、不续期标记。
metrics新增按UID和物理样本去重的：

- `far_fresh_below_30rpm_distinct_samples`：距离>2m、新鲜Depth、批准<30RPM（含0）。
- `far_fresh_below_30rpm_motion_status`：关联估计状态，未知不猜测。

低速计数是诊断，不保证每次都是故障；还要核对危险/目标状态和是否存在真实停止证据。
