# 普通驻车最短保持 300ms 试验

本轮把 `ParkSettlingEvidence.MIN_HOLD_SEC` 从 0.100 调到 0.300 秒，
统一普通居中驻车和搜索接回驻车。计时从 NORMAL 实际写入完成开始，
不是从图像采集、制动请求或反打开始计时。日志输出同一个常量对应的毫秒值。

- 期间维持现有 5A NORMAL，普通旧运动/零速不能解除驻车。
- 300ms 是最短保持时间，不是自动释放时刻，也不是物理停稳保证。
- 原地纠偏与搜索接回仍需新鲜双轮近零反馈、停稳后新图像等现有资格。
- 已授权的前进恢复仍走独立交接，但同样不能绕过 300ms 最短驻车。
  不恢复旧运动指令，不延长视觉/深度期限；恢复运动前仍清 0A 并确认。
- 不增加阻塞 sleep。危险/紧急停车立即抢占，不等待计时结束。
- 不改提前跟转 4RPM、反打 3～6RPM、反打软件截止 80ms 或正常差速上限。

针对性验证包括 100/200/299ms 不得释放、300ms 边界仍需证据、串口耗时不计入
保持时长、搜索和居中两入口、电流 5A→0A、旧图像/反馈拒绝、紧急抢占，以及
停稳后新前进授权恢复。测试时序移至 300ms 之后，并更新新运动的视觉/深度
证据；不能沿用本已过期的停车前授权。

未启动/重启实车程序。300ms 是否足够仍需实测；尤其此前约 445ms 仍有余速，
因此保留反馈检查，不声称仅延长驻车时间就能消除首次过冲。

验证：针对性电流/保持/恢复测试 45 passed；全量 4287 passed、3 failed。
失败仍为原有的距离配置断言及两项搜索方向测试，无新增失败。
