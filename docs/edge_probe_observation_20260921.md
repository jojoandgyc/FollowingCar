# 低分边缘探针不再打断搜索

针对 `run_20260921_150933_25162_d3f5b50b` 的 CAP867：
C0 探针分数0.11679，原始框 `(0,137.19,66.56,412.00)`，中心x=0.052。
原配置一帧即可启动观察，导致CAP869视频中看到前一决策产生的STOP。

## 新规则

- 普通低分人体探针：分数严格小于0.20，并且框中心x≤0.15或x≥0.85，
  不进入停转观察，不累计停转确认计数，不授权接回或换向。
- 使用中心范围，不使用头脚是否贴边；中央的近距离残缺人体不受这条边缘规则影响。
- 其他普通探针：连续两帧位置IoU≥0.20，面积比在0.5～2.0内，再进入原有有界观察。
- 由当前活动目标/强ReID路径提供的匹配框，重叠IoU≥0.5时保留快速观察入口。
  这不是新的身份授权，后续UID、几何、危险和前进授权门控保持不变。
- 原本合格的探针在观察过程中退化成同位置的低分边缘框时，结束它自己的观察。
  不因此解除无关正式候选观察或安全停车。
- 不删除原始检测，不修改YOLO/ReID阈值、搜索方向、搜索RPM、深度授权和电机逻辑。

两个运行配置均启用：

```ini
search_evidence_probe_confirm_frames = 2
search_evidence_probe_min_score = 0.10
search_evidence_probe_edge_min_score = 0.20
search_evidence_probe_edge_center_ratio = 0.15
```

通用门控类保持旧调用兼容（默认edge_min_score=0表示未启用）；主程序显式传入上述参数。

## 可追溯日志

`search_candidate_frame_diag` 保留原始候选；`gate.reason` 在只有被忽略的边缘探针时为
`edge_low_score_probe_ignored`，并记录 `ignored_edge_probes`、门槛及边缘范围。
存在其他合格候选时，仍按它正常决定观察，不会被被忽略框遮挡。
