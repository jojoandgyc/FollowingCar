## 手册与历史阶跃

用户提供的LZ-30EMA_2EC_N说明书，印刷第7页（PDF物理第9页）：

- `0x005F`：闭环加速加速度，整数10～65535，RPM/s。
- `0x0060`：闭环减速加速度，整数10～65535，RPM/s。
- 印刷第16页4.4节：0x06参数写不保存到断电；0x10参数写可断电保存。

## 本轮改动

### 跟随启动诊断/显式配置

- `[motor] ramp_diagnostics_enable=true`：安全启动STOP之后、工作线程之前，
  一次03突发读取005F/0060并打印`LZ30EMA ramp_readback`；不增加每帧串口读取。
- `closed_loop_acceleration_rpm_s`默认空，保留驱动器原值；没有默认提高到600或65535。
  明确测试后，可通过该配置或`MOTOR_CLOSED_LOOP_ACCELERATION_RPM_S`选择整数10～65535。
- 明确配置时先确认独立闭环通讯模式；支持已有实际观察到的mode0/control0x38兼容组合，
  不自动修改模式。与当前值相同不写；需要改变时只写005F一次0x06，再读回确认。
- 不写0060、不改变电流、速度上限、PI、深度期限或身份条件。
- 临时参数在程序退出后仍可保留到本次通电结束，**不是进程退出即恢复**。
- 非法配置在打开串口前报错；写后不符或链路不确定时中止初始化，不静默重试或自动重连。

### 有界直线对照入口

`tools/test_forward_step_response.py --acceleration-rpm-s`为显式实验参数，范围10～1000。
默认省略时维持原来的只读参数行为；不会继承跟随INI里的加速度覆盖值。
仍保留60/100RPM、时间、单轮路程和总路程限制，以及现场确认；仅参数改变，不提高测试速度上限。
共享加速度也影响转向和倒车，不能直接把直线改善等同于整个跟随控制已验证。

以下只打印计划，不打开硬件：

```bash
python3 tools/test_forward_step_response.py --rpms 60 --acceleration-rpm-s 350
python3 tools/test_forward_step_response.py --rpms 60 --acceleration-rpm-s 600
```

实际执行必须由现场人员确认净空、方向及急停条件后加`--execute`并交互确认。
建议先同载荷、同电量完成60RPM的350/600对照，再决定是否进行100RPM对照。
关注onset、t50、t90、左右差异、停止距离和异常；若600并未改善实测曲线，不再继续盲增。
工具不自动恢复旧寄存器值；退出后保留本次临时值，断电恢复原持久值。

本轮只做离线假电机、真实SDK内存串口和CPU分析，未读写实车寄存器，未启动电机。
