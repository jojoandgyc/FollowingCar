# CAP874 错误身份接回修复

## 证据与问题边界

素材：`run_20260921_150933_25162_d3f5b50b`。
CAP874、877 的 ReID 距离为0.1719、0.1649，命中CAP231、285的正确目标模板。
最接近三模板均值也只有0.1978、0.1898；躯干距离则为0.4011、0.3691。
因此仅把全身最小距离换成Top-3均值不一定能拒绝这两帧。
当前检测的新特征通过 `Track.update -> last_feature -> TrackOutput.feature -> IdentityBank.assign`
传入，不是因为轨迹5相同就直接使用旧正确目标的特征。
窄小、残缺裁剪可能影响模型，但这些日志不能区分裁剪、预处理、量化或模型泛化误差的贡献。
本次修身份策略，不更换模型、不全局修改匹配度量。

## 实施

1. 搜索时的明确几何矛盾单独保留。
   新鲜检测、补偿后横向跳变大于 `max(0.50, 2 * handoff_geometry_max_center_jump_ratio)`、
   面积相似度小于0.60时记录矛盾；当前配置对应横向跳变大于0.60。
   CAP874的0.6242、0.4172命中；单纯贴边、尺寸变化、被相机转动解释的位移不命中。
   缺失/过期锚点没有计算出的空间矛盾，仍可走原晚到候选两帧观察。
2. 同一候选的矛盾不能由自身后续局部连续性、锚点超时或重新进入旧位置消除。
   新raw ID若在0.35s窗口内（沿用配置）、补偿位移≤0.10、面积相似度≥0.50，
   且只对应一个冲突事件，也继承矛盾。无可靠局部关联不盲目迁移。
   独立轨迹重新确认UID并通过模板隔离验证、当前框又与新的可信位置连续，才可解除；
   手动身份重置也清除。并非永久按外观封禁某个人。
3. 反方向严格搜索入口使用原0.20阈值，不再自动采用controlled_handoff的0.30。
   反方向强匹配仍可进入两帧观察。原同方向soft候选和局部人体分支不全局收紧。
4. 接回模板隔离期间，冻结全身库距离超过0.30（且无合格的显式局部人体证据）即暂停UID输出。
   后续需要两张新鲜、间隔合格、几何与竞争通过、全身距离≤0.20的图像才恢复。
   内部映射只是待复核假设；拒绝期间不刷新轨迹占用时间、可信几何或模板。
   普通已稳定轨迹继续使用原映射阈值，显式局部人体仍可走独立躯干证据路径。
5. 身份拒绝通过 `identity_control_rejected` 传给控制入口，不得被mapped_uid、
   低质量框转向、确认宽限或几何兜底重新授权。仍保留检测及危险输入。

## 日志与验收

- `mapped_geometry_reject / search_geometry_conflict`：保留原始参考与补偿跳变，
  `reacquire_geometry.search_contradiction_retained`说明已保留的矛盾。
- `search_identity_conflict_inherited`：明确记录raw ID变化后负面证据继承。
- `reacquire_control_verify_reject`：记录冻结库距离、复核阈值和恢复计数。
- `strong_template_count / strong_top3_mean_distance`：补充多模板匹配诊断，不改变距离计算。
- `identity_control_rejected`：确认控制层没有将身份拒绝当成普通裁切框继续跟随。

无硬件回归以原始框、采样时间、转角和可构造的日志距离特征向量验证门控；
不是重新推理原图，也不能证明新模型的误识别率。验证CAP874～926不接回，
包括raw ID变化、再次回到左侧，以及普通正确候选、近距裁切和相机转动保护。
