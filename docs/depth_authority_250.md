# 250ms 深度前进授权试验

主配置 `[astra_depth] longitudinal_sample_max_age_sec = 0.25`，继续运行
`./run_request_0428_modular.sh`。这不是把所有180ms全局替换成250ms。

| 时钟 | 当前规则 |
|---|---|
| 正常前进授权 | 从原始物理Depth采集时间起，最多250ms |
| 新距离控制/PI更新 | 测量年龄仍不超过180ms |
| PI最大积分间隔 | 180ms，断档不补积分 |
| 倒车授权 | 仍最多180ms |
| 人体框窗口 | 现有条件式250ms，不变 |
| 同UID积分记忆 | 350ms，不等于运动授权 |

## 180～250ms期间的行为

只能维持或降低之前已经批准的前进速度。必须有匹配同UID、同物理采集时间的原授权；
身份/视觉状态仍合格，无危险、急停或退出；编码器与原始距离必须在原批准时提供有效的
制动依据。每次读取和真正写电机前继续检查期限及保守停车余量。

余量按原始距离、批准速度与当时实测轮速的较大值、已知接近速度、样本年龄以及既有
减速度/响应延迟模型计算。假设目标可能停止，余量不足就提前撤销，不能为了凑满250ms继续跑。
模型仍未经实车制动标定，不能把本次修改当成碰撞安全保证。

迟到的新样本若年龄已为180～250ms，只能作为进一步减速/停车的证据，不能开始新的前进、
更新积分、推进accepted watermark，或将旧授权截止时间顺延。新鲜样本到达后才正常更新控制。
原sample_timestamp始终保留；重复读取、记录日志或发布轮速不能续期。

周期执行器与非周期直接下发均在轮速反馈读取后再次检查，避免等待反馈期间跨过期限还发旧动作。
超过250ms仍没有新合格样本就撤销前进。明确危险、身份丢失/冲突、急停不等到250ms。
