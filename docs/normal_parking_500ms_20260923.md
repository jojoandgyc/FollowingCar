# 普通 5A NORMAL 制动保持 500ms

按用户多次实测结论，将 `ParkSettlingEvidence.MIN_HOLD_SEC` 从 0.300 改为
0.500 秒。居中驻车、搜索接回使用同一常量，日志随常量输出 500ms。

保留 CAP973 的分阶段退出修复：

1. 从 NORMAL 实际写入完成开始计时，5A 保持 500ms；不从图像或制动请求计时。
2. 到期后执行清 0A、读回确认和一次 0RPM，清电流不要求事先停稳。
   调度及寄存器 I/O 会使实际完成略晚于期限，不是硬实时保证。
3. 软件停车锁不随计时解除。原地恢复/搜索接回继续检查清 0A 后的新鲜双轮
   停稳反馈及新图像；前进独立交接保留，不能恢复旧授权。
4. 紧急/显式停止不受普通定时清电流影响；原有 I/O 故障锁存、清 0A 后
   2 秒停稳超时保护保留。更长 5A 保持不会重置或延长清零后的证据期限。

只改该保持时间，未改转向增益、反打幅度、反打 80ms 截止或轮速上限。
手动停车响应试验工具仍保留多种时长的比较矩阵，没有启动工具或操作实车。
运行程序需正常重启后加载修改。

测试覆盖 300/400/499ms 不提前清流或放行、500ms 清流但不自动解锁、
慢串口的完成时间、持续抖动仍按期退出 5A、新反馈/图像恢复、故障及紧急抢占。

验证：针对性 59 passed；全量 `python3 -m pytest -q tests --tb=no` 为
4400 passed、3 failed。失败仍是既有距离配置断言及两项搜索方向测试，
没有修改这些断言。`git diff --check` 通过。
