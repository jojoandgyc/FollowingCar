# 匹配基速独立预算与下一轮验证

## 范围与实现

基线运行 `run_20260916_211146_28404_ed13a3b5`：移动 CAP160~410，站定 CAP410~508。
本轮只改纵向匹配预算、合格新估计的限速变化及诊断，不修改 ReID、搜索、旋转 RPM、
PID增益、200RPM总上限、250ms受限ROI窗口或180ms物理Depth期限。未操作实车。

- `[distance_pid] matching_base_max_rpm=80.0`：独立匹配基速预算，替代旧的
  `20RPM起步+最多20RPM额外前馈`对匹配基速的限制。不是固定80RPM，也不重复加extra_ff。
- 两次合格物理采样可开始估计，至少三次后才允许超过旧40RPM；上升最多80RPM/s。
  重复/旧样本不能推进斜坡；重置后重新建立证据。反馈验证仍上限100RPM，独立预算
  还受总前进上限限制，不能因为总预算200就假定200RPM反馈已验证。
- 远离近距离区、距离未明显缩短（补偿后变化率>=-0.03m/s）、估计仍为正时，
  基速下降最多80RPM/s。靠近或距离<=设定值+0.20m时，不用这一下降限制，
  也不让旧目标速度EMA拖延减速。目标停止证据、危险、UID变化、异常或过期仍走原拒绝。
- 下发层同步取消对合格匹配基速重复套用旧40RPM限制。只放行传入的合格估计；
  无估计时普通近距离限速不变。死区外保留最多20RPM请求的追赶修正及原远距总限幅；
  明确零输出不会被抬高，倒车限幅不变。
- 短时转动桥接仍按原180ms截止时间退出；本轮没有解决所有 fresh/bridge/none
  切换掉速，也没有延长授权或声称实现独立30Hz跟踪。

回退匹配预算与新限速行为：设 `matching_base_max_rpm=0`，重启后恢复旧预算。
代码默认0，只在正常运行INI开启80；旋转专用配置不因本项新增而开启前进。

## 视觉过期：仅审计，不放开

旧路径同时撤销横向输出、调用方向恢复、改变身份/搜索控制资格。仅保留深度tuple
既不能保证恢复执行，也可能破坏搜索安全边界。本轮新增 `stale_vision_depth_audit`，
记录UID、物理深度年龄、剩余期限及前馈期限，保留原撤销政策。
其中剩余深度期限>0只表示值得核查，不代表该次撤销必然错误。

## 指标与工程试验目标

移动段与站定段分开统计，保持1.5m设定、相近走速/路线/光照；按真实采集时间，
不能用CAP差除30。本次移动段采集时长13.354s，指令窗口尾随180ms。
以下目标是下一轮试验标准，不是已取得的效果：

|指标|本轮修改前基线|下一轮目标/检查|
|---|---:|---|
|移动平均绝对距离误差|0.967m|先降到<=0.70m，再向±0.15m推进|
|移动最大距离|2.971m|<=2.70m；不能只看最终追回|
|新鲜匹配记录触顶比例|52/75=69.33%|争取<30%；结合实际cap和samples区分40RPM预热与80RPM预算|
|200ms内PID请求下降>10RPM|13次，9.61次/10s|争取<=5次/10s，剔开必要安全减速后看非安全切换|
|200ms内批准速度下降>10RPM|9次，6.65次/10s|争取<=4次/10s，同样不能削弱安全停车|
|零轮速指令时间占比|10.13%|不恶化；零指令不等于实测静止|
|新鲜正向深度授权|15.57Hz；最长343ms；8个>180ms间隙|不恶化；间隙率基线5.91次/10s|

站定单独看：CAP410距离2.806m，到CAP466进入<=1.65m用3.042s，到CAP473约1.501m
用3.378s；站定最低1.445m，最终1.484m。下一轮不得以更大近距离过冲换取追赶速度。
站定后正常停车不要混入移动段作为异常；发现身份错误、异常远值或近距离过冲应先停测。
首次验证需空旷低风险场地、有人急停，不能依据控制器支持200RPM推断整车安全能力。

## 日志口径

- `longitudinal_motion` 增加 unbounded_target_rpm、matching_cap_rpm、matching_rate_limited；
  原有samples、range_rate、target_speed、状态、转动补偿字段一起分析。
- `distance_pid`增加UID；`depth_linear_limit`记录同物理样本的PID请求、批准RPM和差值。
  没有同样本PID则写None，不把旧PID归到新深度。损失是限幅损失，不是实际轮速误差；
  最终串口执行仍需结合电机日志核对，提前拒绝而没进入该日志的样本不在此分母。
- 短降速指标按同UID、递增物理样本去重，记录时间200ms内下降严格大于10RPM；
  按fresh/bridge/none等来源转换分类，零输出单列。来源不是已证实的根因。
  老日志缺UID时仅适合同一目标片段；缺字段不补零、不推测。
- `tools/follow_metrics.py --compare-run`加入触顶、短降速与请求损失比较。

下一轮运行后执行（把 NEW_RUN 替换为目录，CAP替换为实际移动起止）：

```bash
python3 tools/follow_metrics.py NEW_RUN --cap-start 160 --cap-end 410 --target-distance 1.5 --compare-run run_request_0428_modular_logs/run_20260916_211146_28404_ed13a3b5 --compare-cap-start 160 --compare-cap-end 410
```

更高匹配基速可能改善跟上速度，但若40RPM预热反复重启、桥接退出仍频繁，
触顶下降也不等于跟随成功。以距离误差、安全和真实轮速联合验收，不继续盲加P。
