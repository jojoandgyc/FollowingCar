# 近距离横向明确驻车（CAP42～85）

## 目标与边界

修复“已触发预测停车/中心保持，却持续下发0RPM而未进入NORMAL驻车”。
不是把距离小于1.5m的全部转向禁止，也不是把所有forward(0)升级成整车停车。
本轮不修改PID、RPM、身份识别、搜索方向规则、深度阈值或授权有效期。

## 控制与执行契约

1. 近距离纵向目标为零，且横向明确预测停车、中心保持或真实居中回退时，控制器设置
   `near_yaw_park_requested`。普通PID瞬时零、方向保护仍保持原软零语义。
2. 视觉发布者或帧间PID预测停车建立不可变停车请求，记录UID、真实采集帧/时间、原因。
   如果仍有有效的纵向授权，则仅撤销轮差，保留等速前进，不进入此驻车。
3. 动作线程优先消费请求，取消旧旋转脉冲，执行`NORMAL STOP`一次。持有请求期间，
   FOLLOW20、forward(0)、软零、旋转续发及切换零速不能覆盖驻车。定期驻车刷新仍为NORMAL。
   不把速度目标0称为自由滑行，也不假定NORMAL立即让机械角速度归零。
4. 进入和释放时清旧队列、当前命令，并增加停车代次；已出队但尚未执行的旧动作也被拒绝。
   锁顺序为command → motor → queue；队列消费者在queue锁内读代次，放锁后取得command锁复核。
5. 只有更新鲜的物理视觉帧（CAP与采集时间均推进）、同UID、质量可控、明确非零修正/移动
   请求才释放普通驻车。重复帧、新处理序号、Depth零指令均不构成释放依据。
   后续中心帧只推进释放证据门槛，不重启驻车计时、不重复启动停车事件。
6. 明确丢失/搜索及身份切换由更新鲜的视觉决策交接，沿用原搜索规则，不新增固定停等时长。
   危险/急停始终优先；普通驻车不能降级或解除更高优先级安全状态。
7. 驻车时可信同UID视觉仍可用latest Depth测量；恢复释放发生在当前视觉样本的深度授权提交
   **之前**，避免首张恢复样本白等一轮。释放本身不恢复旧授权，新前进仍通过原深度安全检查。

## 诊断日志

- `near_distance_rotation_only ... park_requested=... park_reason=...`：控制器停车意图。
- `near_yaw_park_requested`：停车事件、UID与证据CAP。
- `near_yaw_park_applied ... request_age_ms=... mode=normal`：实际停车下发完成。
- `near_yaw_park_write_blocked`：旧零速/旧动作被拦截（限频打印）。
- `near_yaw_park_queue_veto`：停车代次边界上的过时队列动作被拦截。
- `near_yaw_park_released ... held_ms=... reason=...`：新证据恢复或状态交接。

## 下轮验证

仍运行原启动脚本；首次验证保持场地空旷并准备急停，不由开发测试启动实车。

| 指标 | 原CAP42～85片段 | 本轮验证要求 |
|---|---|---|
| 预测停车是否真正发送NORMAL | 多次0RPM后才发送 | 每次有效明确停车均有对应applied日志 |
| 停车请求到NORMAL完成 | 原首次0RPM到NORMAL约402ms（不同起点，不能直接当同口径） | 记录request_age_ms分布；排查超过50ms事件的执行/串口等待 |
| 驻车期间普通速度包覆写 | 有STOP被forward(0)替代 | 0次；拦截日志不等于实际发出 |
| 重复/旧帧解除驻车 | 需结合来源核对 | 0次，释放CAP与采集时间均晚于最后停车证据 |
| 实际停转时间/多转角 | 首次0RPM到首次双轮零反馈约300ms | 另统计NORMAL后连续低轮速/低角速度时间及积分角度，不把单次0反馈当停稳 |
| 停稳后正常恢复 | 本段另有左搜与再次右修正 | 明确偏离中心、直线远离、正常搜索均可恢复，无新增固定等待 |

不同路线/目标运动不能直接作严格对照。改动验证重点是停车意图与电机执行一致性，
不保证解决本片段所有身份中断，也不能用更快停转的假设代替实车编码器验证。

离线测试使用假驱动，不打开串口、摄像头或启动电机线程：

```sh
python3 -m pytest -q tests/control/test_near_yaw_park_decision.py tests/control/test_near_yaw_park_runtime.py tests/control/test_near_yaw_park_depth.py tests/motor/test_near_yaw_park_execution.py
```
