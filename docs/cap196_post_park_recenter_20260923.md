# CAP196：停稳后的轻缓原地找正

## 依据与范围

复核轮次：`run_request_0428_modular_logs/run_20260923_154030_23826_fac23090`。
CAP192 控制位置约 0.337、CAP196 约 0.319，按 66° 视场和原有位置映射，
即使没有启动补偿也直接达到单轮 7RPM。恢复后的左转持续建立，随后仍越过中心。
这次不全局调低 P，不增加反打，不延长驻车，也不操作实车。

## 控制变更

- 普通驻车为当前 UID 标记一段“再次原地找正”状态。该标记只是限幅，不授权运动。
  原有停车后新图像、500ms 驻车、清 0A、清电流后停稳反馈等释放检查仍先执行。
- 在 image-error 模式、非搜索、同 UID 的原地修正中，单轮修正上限为 4RPM，
  即双轮差最多 8RPM。主循环、横向快环首拍/重算/斜率限制及最终轮速写入都遵守此上限。
  修复普通动作转换的旧 5RPM 下限，避免较小 PID 输出被再次抬高。
- 4RPM 是上限，不是强制下限。原位置映射缩放后，可在靠近中心时连续降至 3、2、1、0RPM；
  已有更低上限、提前制动、到期撤销和危险停车优先。
- 不按固定时间恢复 7RPM。新的有效前进/后退接续结束该限幅；或停车释放后，
  连续三张独立可信图像确认明显持续外移时结束：跨度 80～350ms、最新年龄不超过 250ms、
  同 UID/raw track、普通有效速度证据、同向速度 8～60°/s、偏差至少 15°。
  旧帧、仅制动几何、回中心、小偏差不能解除。目标清除/变更也清除状态。
- 正常前进差速不受 4RPM 限制；首次原地纠偏仍使用原有上限。

## 首次回中心的减速证据

CAP194→196→199 的原始中心约 0.3230→0.3193→0.3255。普通速度估计因方向变化
仍应判为 `rate_inconsistent`，不能把这次反向增量当作稳定运动趋势。

新增独立 `inward_turnaround_rate_dps`，仅来自同一可信几何链的三张图：
前一增量外移、最新增量内移、三点仍在中心同侧；跨度不超过 350ms；最新间隔 50～250ms，
最新位移至少 0.004 画幅，最新速度 3～60°/s，两段速度差不超过 40°/s。
UID/raw track 变化、缺失/低置信/几何异常、超时或小抖动不产生该证据。

只有新鲜、可信、原始/滤波一致且方向匹配的实测角速度已允许减速时，这条辅助证据才生效：
将原地同向输出限制到位置请求的 75% 以下（4RPM 可提前收至 3RPM），取现有制动结果与其较小值。
它不替代普通视觉速度、不授权前进/身份确认/提前跟转/反向制动，不增加输出。
生产者必须验证同 UID、同 CAP、同采集时间，再把证据绑定到不可变横向意图交给快环；
快环重新检查当前反馈和图像年龄，不能靠重复读取延长授权。
