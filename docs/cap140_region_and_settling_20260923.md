# CAP140–151：建库区域、可比性和停稳补看

基线：`run_20260923_214409_60074_a8b8ced1`。本轮不启动相机/NPU/电机。

## 行为变化

- 运行配置启用 `identity_bank.appearance_region_safety_enable=true`，经环境、pipeline、tracker 传到 IdentityBank。独立库默认保留旧模式，便于对照；新策略回归显式开启。
- 新建身份要求新鲜、强质量、未贴边、至少 80×160、宽高比 0.25–0.85 的检测裁剪。CAP27 这种侧面残片返回 `initial_crop_incomplete`，不创建 UID、不建立模板。该要求仅用于新建，不禁止已知目标的正常贴边观察。首次使用应让人体完整进入画面；这是几何完整性检查，不等于模型已确认人体部位或清晰度。
- 躯干可靠证据只在相同 top/bottom/side 覆盖类型且宽高比可比的可信模板中选择。原始跨区域距离继续记录；没有可比模板时是 `unknown / secondary_evidence_unavailable`，不能作为支持或反证。已有几何/外观矛盾不因此清除。覆盖类型仅是保守代理，不是姿态/关键点对齐。
- 当前唯一候选、当前 UID 竞争通过、质量合格、近期全身距离不超过 0.55、无明确身份/几何冲突且缺少可比躯干证据时，可作为 `unverified_stop_only` 候选。仍须两张新采集图像的局部连续性，才能申请一次额外 STOP。0.55 只决定是否值得停车补看，不是身份接回阈值；不写库、不改方向、不授权前进。
- 普通观察和额外补看均检查成功零速下发时间、两条不同时间的新鲜可信编码器反馈（左右轮绝对值均不超过 1 RPM、无编码器错误），以及晚于停稳证据且至少在零速下发 80ms 后采集的新图像。重复反馈、运动中反馈、旧/未来/错误反馈不能证明停稳。
- 保持最长 300ms 窗口。超时记为 `observation_timeout_unsettled` 或 `search_retry_timeout`，不记为核验成功，也不增加身份权限；原搜索和独立安全控制决定后续动作。图像过期、危险、身份冲突仍生效。窗口内若仍未停稳，不能保证补看有收益，需下次日志验证。
- 普通候选消失或跳变时释放观察，不把旧框冒充当前候选。候选观察超时不得向方向观察链声称“确认完成”。
