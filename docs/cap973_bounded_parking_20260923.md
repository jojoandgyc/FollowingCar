# CAP973～1100：解除普通驻车电流与恢复运动分离

CAP973～1100 约 6.62 秒没有新速度包，但反馈持续正负往返。严格停稳门槛

## 本次改动

- 保留当前 300ms 参数，从 NORMAL 实际写入完成计时，不从图像/请求时间计时。
- 普通居中驻车、搜索接回制动统一使用执行线程的退出步骤：到期即清左右轮
  驻车电流至 0A，读回确认后只发一次 0RPM。无须先停稳或先获得运动资格。
  该步骤不清理软件停车锁，不发前进/转向，不恢复旧授权。
- 周期性驻车保持刷新也服从同一状态，不得再次下发 NORMAL 恢复 5A，
  不得重置计时。新的真实停车事件仍正常恢复 5A。
- 清电流和零速写入完成之后重新收集反馈，之前的停稳样本不能解锁。
  原地恢复/搜索接回仍需两个新鲜近零样本（≤1RPM，跨度≥40ms）以及
  停稳后的新图像。已有前进独立交接仍保留，但也必须经过 0A 确认，并检查
  之后的新图像/反馈及原有身份、深度、车轮反转保护。
- 清电流或零速 I/O 失败、清电流后 2 秒仍无有效停稳证据时，记录
  `ordinary_park_exit_fault` 并尝试紧急停车。故障锁存于电机后端，不因换目标、
  更换停车请求或晚到的静止样本自动恢复；非零输出被禁止，普通 STOP 也不能
  重新进入 5A NORMAL。需要人工检查、确认安全后重启运行程序。
- 紧急/显式停止/退出不属于定时解除范围。电流或零速 I/O 期间发生危险或
  停车所有权变化，立即转入保护，不继续恢复流程。

300ms 是执行线程检查的制动期限，实际清零完成还包含线程调度和寄存器
I/O 时间，不是硬实时保证。0A 零速闭环能否使本车稳定仍需实测；本次没有
修改驱动器固件、P、转向峰值或反打幅度，也没有操作实车。
