# 60/100RPM、5/10A、300/500ms 驻车对比测试

脚本：`tools/test_parking_stop_response.py`。默认只打印八种组合，不打开串口。

```bash
python3 tools/test_parking_stop_response.py
```

## 现场条件与启动

- 停止主跟随程序及其他串口工具；脚本检查进程、串口占用，并与阶跃测试共用端口锁。
  锁是协作式保护，不能阻止不遵守锁的其他程序。
- 必须核实电机、驱动器和电源允许的电流。脚本支持10A不代表已经证明硬件能承受10A。
  `--rated-current-a` 填已核实的安全上限；任一侧实测相电流超过它立即终止。
- 固定台架先验证接线方向；架空数据不能作为落地停车距离/车身稳定性结论。
  地面测试应在平整、无人的充足空地，操作人员准备独立物理急停。
  本脚本不运行避障，不保证断线、进程被强杀或主机卡死时能停车。
- `--motion forward` 是双轮同向直行；`left/right` 是原地旋转。
  转速指每轮绝对RPM；**原地±100RPM的轮差是200RPM，远高于跟随微调，不能混淆**。
  脚本没有默认实测方向，不会代替操作人员选择。

先单独选择60RPM/5A/300ms。下面命令会先要求输入核实过的安全电流上限，
再由脚本要求输入 `PARK`；每一组还必须现场输入 `RUN`，不会自动连续启动：

```bash
read -r -p '已核实的电机/驱动器安全电流上限(A): ' parking_test_safe_current
python3 tools/test_parking_stop_response.py --execute \
  --motion forward --setup ground --rated-current-a "$parking_test_safe_current" \
  --rpms 60 --currents 5 --holds-ms 300
```

核实场地和首组表现后，省略最后三个筛选参数可测全部八组；每组可重新定位车辆。
`--setup bench` 明确标记台架；更改方向需显式指定 `--motion`。
参数：启动达到目标超时默认2s（最大3s）；各轮单次累计编码器路程默认上限2m
（最大3m）；轮径默认0.26m。路程保护是采样后的应急保护，不保证不超过该距离。
不要为了凑到100RPM盲目放宽超时/路程限制。

## 每组时序

1. 清0A、双轮零速，确认连续静止。
2. 下发60或100RPM；两轮各自实测速度在目标±5%（至少±3RPM）内持续200ms，
   并核对编码器位移支持该方向和速度；未达到则中止，不伪装成该档停车数据。
3. 设置5或10A，使用非持久寄存器写入并回读确认。再次测轮速，档位已变化则中止。
4. 分别记录左右NORMAL写入起止时间。NORMAL前后不插入额外零速命令，避免混入
   提前滑行或把驻车覆盖成速度模式。保持时间从两轮NORMAL都完成开始计算。
5. 保持300或500ms后清0A、发送双轮0RPM，继续观察500ms，检查释放后的滑移/抖动。
6. 每组结束急停、清0A，等待现场下一次确认。异常/Ctrl-C/SIGTERM走同样清理，
   清理失败明确提示物理急停。运动写入失败不重试，不修改PID、控制模式、加减速参数。

保护：电机故障、非有限反馈、样本过期/串口过慢、错误运动方向、超速、相电流超限、
板温达到60℃、编码器突跳、累计路程超限、单组超过8s均终止。
这些是软件兜底，不替代硬件急停。

## 如何判断“停住”

每轮分别判定驻车截止前最后100ms：至少3个有效样本，覆盖至少50ms，首尾误差
不超过60ms、样本最大间隙75ms，绝对轮速≤1RPM，编码器位置范围和累计移动均≤2°。
释放后的500ms也检查整个窗口，而非只检查最后一帧。该容差是可复现的编码器判据，
不是数学上的绝对静止，也无法检测车轮锁死但车身滑动、摄像头晃动。

- `encoder_stable`：两轮都满足驻车截止及释放后稳定判据。
- `not_stable`：有效证据显示至少一个窗口未稳定。
- `inconclusive`：采样不足/跨度不足/释放晚于计划50ms以上等，不计为成功。
- `aborted`：未完成档位资格确认或出现安全/通讯故障。

结果在 `calibration/parking_stop/`：JSON保存参数、控制器模式、全部事件时间、
原始采样和每轮判定；CSV保存逐轮原始反馈。每次完成及退出都保存，异常保留部分数据。
还记录NORMAL完成前后的时钟、释放起止时间、逐轮实际保持时长区间及最早观察到的
连续静止确认时刻。不拿异步左右轮反馈冒充同时采样，不用300ms以后的样本证明
300ms内停车。脚本退出码0表示全部已执行组合通过判据，3表示完成但有未稳/未知，
1为异常或中途结束，2为参数错误/首次未确认。

下一步用实测结果比较同一运动方向、相近实测入场轮速下5A/10A和300/500ms，
并通过录像/外部测量确认车身是否仍移动。当前仅做无硬件测试，没有实测结论。
