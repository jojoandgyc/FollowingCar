# 录像吞吐与真实时间回放

本轮只修改录像路径，不修改电机、身份确认、深度授权或控制参数。

- 后台使用 OpenCV JPEG quality=90 编码，再由 FFmpeg packet-copy 封装 AVI；不进行二次编码。启动不可用时回退原 OpenCV writer。
- 绘字使用 LINE_8，保留轮速、目标速度及深度 ROI 数值等诊断信息。
- 队列仍为 60；满队列提前拒绝，避免无效 RGB 拷贝。不阻塞采集等待录像，不修改全局 OpenCV 线程数。
- VIDEO 是保存序号，CAP 是采集序号，不能人为合并。新增 T+ 为相对首张保存帧的真实采集时间。
- CSV 新增 recording_* 分项耗时、队列年龄、CAP 缺口和累计丢帧；日志每 5 秒及结束时输出最近 120 帧各项平均/P95/最大耗时。

640×480 同帧离线测试：绘制中位数约 9.93→3.31ms，编码写入约 11.84→2.29ms。不是实车并发负载结果，后台仍会共享 CPU、内存和磁盘，不能保证零影响或零丢帧。

运行命令不变。回退编码后端：

```bash
FOLLOW_VIDEO_FAST_MJPEG=0 ./run_request_0428_modular.sh
```

## 按真实时间回放（停车、结束运行后执行）

原 AVI 为固定帧率，有丢帧时播放会加速。离线工具按对应 CSV 的采集时间生成可变帧率 MKV，不覆盖原录像，不补造丢失画面，不自动在小车运行期间执行：

```bash
python3 tools/retime_recording.py run_request_0428_modular_logs/<本轮目录>/camera_raw.avi
```

输出同目录 camera_raw.realtime.mkv。缺失期间保持上一张真实画面；末帧之后无额外时间推断。工具只复制 MJPEG 包，临时逐帧 AVI 用于兼容板载 FFmpeg 的毫秒时间基；需要额外临时磁盘空间。必须使用本轮配套 CSV。

## 程序结束后自动另存 MP4（2026-09-28）

运行入口仍是 `./run_request_0428_modular.sh`。默认在 Python 跟随进程、录像和输出日志收尾后，把**本轮日志目录**的 `camera_raw.avi` 另存为 `camera_raw.mp4`：

- H.264 / yuv420p / faststart，便于 VS Code 和常见播放器预览；画面中的诊断文字保留。
- 使用同目录 `camera_raw.frames.csv` 的采集时间，丢帧时保持上一张画面，不按固定 30FPS 压缩真实时长，不伪造丢失帧。末帧之后不额外推断持续时间。
- 保留 AVI/CSV；转码成功并核对帧数、时间戳后才发布 MP4，不覆盖已有 MP4。取消或失败时清理本次临时输出，原文件不动。
- 转码不在运控/录像线程内进行，也不占用 8 秒安全退出期限；单线程、低优先级。启动器持有会话锁到转码结束，避免另一个同入口跟随进程与它争用资源或轮换其输入目录。
- Ctrl+C 导致小车正常清理退出时也会转码；强制终止、非零运行退出码、录像未完整关闭时不自动转换。没有录像时不新增录像开销。
- JPEG 封装子进程使用独立信号会话：终端 Ctrl+C 先让主程序完成安全停车和录像排空，封装器通过 stdin EOF 正常退出，不再与主程序同时被终端信号打断。超时强制回收仍保留，不改变电机停车逻辑。
- 终端显示完成路径；详情在本轮 `video_export.log`。转码期间可再次 Ctrl+C 取消。大录像需要等待并占用额外临时磁盘空间。
- 本功能只覆盖本轮日志目录的默认录像；自定义目录录像使用下方手动命令。缺少 `flock` 时自动转码跳过；缺少 FFmpeg/libx264 时只报告失败，不影响原运行退出码。

关闭自动转换：

```bash
FOLLOW_VIDEO_EXPORT_MP4=0 ./run_request_0428_modular.sh
```

已有完整录像手动转换（只在小车停止后执行）：

```bash
python3 tools/export_recording_mp4.py /完整路径/camera_raw.avi
```

不要把 AVI 直接改扩展名为 MP4；这不会改变其 MJPEG 编码和容器。

实测旧录像 `run_20260928_193724_15424_54fd3211` 有 646 个 AVI 视频包，但 CSV 有 647 行，日志同时报告 `JPEG muxer stopped`。该文件本轮试转被一致性校验拒绝，未生成 MP4，原 AVI/CSV 未改动；新的信号隔离修复不能补回旧录像已丢失的数据。
