## 本次实现

- **区域比较分级**：优先原覆盖相同、形状可比的近期证据（包括此前的小幅形状迟滞）。
  精确区域有反证时，不用宽松区域的低距离覆盖。若没有精确区域，才允许上下边界之一不同、
  两侧均未裁切的较完整人体比较：宽≥图宽15%、高≥图高55%、宽高比0.30–0.85，
  两框形状相似度≥0.75、归一化高度相似度≥0.70。形状已经限制变窄，不另用宽度比例重复限制侧身。
  这只是固定ROI可比性的保守近似，不声称肩髋/人体姿态已经对齐。两侧裁切分清左右，
  不再把左侧残片与右侧残片仅凭同一个side1标签判成同覆盖。
- **老模板角色分离**：新增最多6张/类型的已批准区域代表，按实际采集时间保存，沿用120秒
  archive窗口。近期仍为30秒；过期代表只输出`observation_only`辅助诊断，绝不填充近期距离、
  授权下限或解除隔离证据。候选命中不会续期。身份源被判矛盾时，同源代表也追溯隔离。
- **隔离新增同源证据路径**：全身与躯干必须匹配同一CAP、同一采集时间、同一原始轨迹和裁剪
  的近期已批准模板，全身≤0.30且躯干≤0.26；原0.20强全身路径不放宽。还需当前UID已绑定、
  新鲜强质量、身份竞争通过、几何连续、没有历史矛盾/待恢复怀疑、已退出搜索。新路径需要至少
  5张连续新帧，且合格证据持续至少1秒；不能用早先等待时间补足这一秒。证明期间模板冻结，
  重复、乱序、断档或条件失败清除进度。两种证明不能混合累计。
- **补齐部分接回后的入口**：`mapped_late_continuation`本身仍不能写库；退出搜索后，
  新帧若满足同源近期证据，可交回正常复核/隔离路径。避免一直通过提前返回而永远没有写库资格。

新增日志：`comparison_mode`（`exact_coverage`/`vertical_border_bridge`/`unavailable`）、
`regional_representative_evidence.permission`、`quarantine_region_pair`、
`region_pair_confirming`/`released_region_pair`、`partial_continuation_regular_verification`。
旧身份矛盾、竞争排除、模板污染追溯、深度时效和电机授权检查保留。
