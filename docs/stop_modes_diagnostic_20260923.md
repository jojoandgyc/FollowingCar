# 停车模式独立诊断：2026-09-23 19:07～19:11

## 测试范围与结论

现场用户确认有人看护且可独立切断电机电源后执行。未运行跟随主程序，
未修改跟随参数、控制器模式、加减速寄存器或持久配置。

结论：低速前进后的三个停车方案均最终稳定，但都不是瞬间停止轮动。
没有复现原日志中持续多秒、幅度增大的前后振荡；不能据此排除运行历史、
旋转负载、较高速度等条件下的问题。原地左转试验在驱动阶段因保守电流
限制中止，未进行到计划中的 NORMAL；不能称其为 NORMAL 失败。

现场没看清前三次低速试验，故没有把轮速/位置遥测冒充独立的实际轮动观测。
中止后用户确认车已停止；最后一次只读检查也确认双轮稳定。

## 新脚本

`tools/test_stop_modes_diagnostic.py` 默认仅打印计划，不打开串口。

```sh
python3 tools/test_stop_modes_diagnostic.py
python3 tools/test_stop_modes_diagnostic.py --read-only
# 必须有人全程看护，能独立切断电机电源。每次只执行一项。
python3 tools/test_stop_modes_diagnostic.py --execute --attended-power-cutoff --case normal-free --rpm 0
python3 tools/test_stop_modes_diagnostic.py --execute --attended-power-cutoff --case free --rpm 8
python3 tools/test_stop_modes_diagnostic.py --execute --attended-power-cutoff --case emergency --rpm 8
```

执行模式在任何试验写入前检查静止状态。允许转速仅0或4～12RPM，非零指令
持续500ms，不进行自动矩阵或自动重试。左右轮分别记录每次写入起止、应答，
驻车电流双轮读回，以及实测轮速、位置、电流、PWM、温度、错误码。
读回的驻车电流是设定值，不能当作实测相电流。

- NORMAL路径：双轮目标0 → 双轮5A并读回 → NORMAL(0) → 保持500ms → 清0A并读回 → FREE(2)。
- FREE路径：0A已确认，非零转速后直接FREE(2)，没有额外零速写入。
- EMERGENCY路径：0A已确认，非零转速后直接EMERGENCY(1)，没有额外零速写入。
- 观察结束后单独标记清理阶段：双轮EMERGENCY、清0A并读回，再观察500ms。
- 只读模式包括关闭连接都不发送速度、停车或电流设置指令。
- 串口互斥锁和进程/端口占用检查；不自动终止其他程序。
- 电流>6A、速度>20RPM、累计编码器路程>65轮角度、温度≥55°C、驱动故障、
  反馈超时或连续两次明显反向即中止。6A是此诊断的保守中止线，不是电机额定值。
- 清理分别尝试双轮，即使一侧失败也尝试另一侧；不能确认停稳时提示物理断电。
- 停稳判据：最新约250ms，至少4个样本且覆盖≥200ms，绝对轮速≤1RPM，
  编码器累计变化≤2°，无故障/过大采样间隔。不是仅看最后一帧0RPM。

这些监测不是独立硬件安全装置；进程崩溃、通信中断、控制器不响应时仍需现场断电。

## 实测结果

控制器：36V，runtime/configured模式0，control_mode=0x38，FOC loop=1；
加速/减速寄存器350/450RPM/s，原样保留。它们不是350ms响应时间。
左右轮顺序采样，周期约28ms；时间从双轮STOP写入完成计，不包含此前设置电流时间。

| 试验 | 停车前实测左/右RPM | 后续保持0RPM的首个采样时间（左/右） | 结果 |
|---|---:|---:|---|
| 静止5A NORMAL → 0A FREE | 0/0 | 全程0 | 位置、电流、PWM亦无变化 |
| 8RPM前进，5A NORMAL → 0A FREE | 8/8 | 482/451ms | 观察末尾稳定 |
| 8RPM前进，0A FREE | 9/9 | 618/920ms | 观察末尾稳定；右轮后段包含−1RPM小反馈 |
| 8RPM前进，0A EMERGENCY | 9/8 | 480/476ms | 观察末尾稳定 |
| 单轮±8RPM原地左转 | 尚未进入计划停车阶段 | 不适用 | 左轮6.09A，试验中止 |

以上“保持0RPM”只是后续采样中不再出现非零值，不等价于精确物理停止时间，
也不等价于脚本较宽松的≤1RPM停稳判据。单次试验不能据此给三种模式作可靠性能排名。

8RPM NORMAL的细节：

- 左轮NORMAL后实测相电流最高1.63A，电流/PWM约344ms后持续为0。
- 右轮相电流/PWM约87ms后持续为0，但轮速之后仍非零。
- 从第一条停车后样本到观察结束，左轮位置−675→−667°、右轮885→875°。
- 清0A＋FREE在NORMAL后约515ms完成，此后没有再次发非零速度。
- 到500ms时虽然轮速已接近/达到0，尚未积累足够连续安静窗口，
  所以 `quiet_at_500ms=False`，并不是“500ms时仍持续高速转动”。

EMERGENCY的细节：左右轮电流/PWM分别约91/60ms后持续为0，
轮速则约480/476ms后持续为0。说明驱动输出遥测归零与轮速归零之间存在明显时间差。
仅凭总线反馈不能独立验证功率级是否完全断驱或排除机械/反馈因素。

原地左转中止：

- 发送单轮±8RPM约399ms后，左轮实测−4RPM、6.09A、PWM17.3%，温度30°C、错误码0。
- 两侧EMERGENCY均应答；两侧驻车电流清0A并读回成功。
- 清理观察末尾双轮反馈仍约+2/+2RPM，未满足连续停稳判据；程序退出非零状态并提示断电。
- 没有继续升高电流/速度限值来强行完成试验。
- 用户随后确认车已停止。19:11只读检查：双轮轮速、电流、PWM均0，位置固定，驻车设置0A。
