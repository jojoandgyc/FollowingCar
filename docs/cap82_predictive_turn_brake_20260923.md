# CAP82：预测反打与 NORMAL 制动交接

## 证据与修复范围

运行 `run_20260923_124515_8127_e3643a84` 的 CAP82 已算出 -2RPM
预测反打，却被 `target_still_outside_center` 清零。只放开方向检查仍不足：
普通车轮反转保护也会将反打清零。本次将受限反打作为停车请求的短时制动阶段，
不作为普通反向转向命令；普通反转保护不变。

## 行为

1. 相机主控制和横向快环仅放行带完整预测制动证据的原地反打。
   要求新鲜、可信的图像接近速度与同向余转反馈；普通相反方向输出仍被拒绝。
2. 无有效前进授权、可信可见目标、确认低速原地余转时，锁存停车请求。
   反打单轮修正不超过 2RPM（双轮差不超过 4RPM），软件期限 80ms，不能续期。
   不强制维持最小时长：余转消失、反馈过期或乱序、目标丢失等立即结束。
3. 后续接回既有 5A NORMAL 驻车，100ms 最小保持从 NORMAL 实际完成计时，
   仍需停车后新图像及停稳反馈才能恢复。反打证据本身不能解除驻车。
4. 原地预测提前量计入反打阶段的 80ms 预算，避免单纯推迟 NORMAL。
   正常前进差速预测参数不变；既有 20RPM 总轮差、14RPM 原地轮差上限不变。
5. 模式切换 I/O 后重新检查授权和危险；写入失败尝试紧急停车，不重放反打。
   串口写入已耗尽期限时，不等下一个控制周期就接回停车。

80ms 是现有控制循环检查的软件期限，不是硬实时保证，更不是电机实际反转
或停车耗时保证。调度、串口、驱动器及机械响应仍需实测。小反向速度目标是否
比直接 NORMAL 更有效，不能由无硬件测试证明。

本轮不改变意图过期策略、深度授权或普通前进/反转保护，不操作实车。
