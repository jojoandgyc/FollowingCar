# 中心/预测驻车最短保持 100ms

## 核对

2026-09-21 23:21:20 运行日志第 71 行确认左右驻车电流均为 5A，
第 14244 行下发 search_reacquire_brake NORMAL，第 45487 行退出才清为 0A。
不能把 CAP735–737 残余运动归因为本轮未设置驻车电流；日志证明的是参数读回，
不是每一时刻的实际电流或车身制动力。

## 改动

- ParkSettlingEvidence 统一要求 NORMAL 实际写入完成后至少 100ms 才有资格释放。
- 同时覆盖中心驻车的普通运动接续、停稳释放、搜索接回释放及其深度恢复入口。
- 不使用 sleep；急停不受影响，反馈仍按原周期采集。
- 时间到不自动启动，不清除驻车电流；原有身份、新图像、反馈和运动授权检查继续生效。
- 普通差速跟随的零轮差、软零速和前进失权交接不因此改成 NORMAL。
- 停车日志增加 parking_current_a 和 current_source=startup_readback_cache，
  表示已确认设置的缓存，不冒充实时测量电流；不增加串口读写。
