# CAP1253–1279：覆盖分组变化与身份恢复接续

## 修复边界

保持躯干确认线 0.34、观察线 0.45 不变。0.34–0.45 的待核验帧仍输出
UID0，不更新模板、不授权电机，也不增加身份确认计数。

同一已绑定轨迹在覆盖分组切换时，即使尚未进入搜索，也可以维护独立
候选观察轨迹。进入搜索时保留其几何连续性，但从新搜索方向重新统计
跨侧证据。此观察最多保存现有 3 秒窗口，逐样本间隔仍受现有 350ms
约束；原可信位置和模板不被未确认候选覆盖。

已经有一帧合格接回证据时，中间的灰区帧只在逐帧连续、无竞争或身份
矛盾的情况下保留该证据。灰区不刷新这张合格样本的时间戳、特征或计数。
第二张合格外观证据仍必须在原 350ms 确认窗口内出现；超过期限、缺帧、
乱序、质量不合格、缺少转动信息、轨迹改变或明确矛盾均不能这样接续。

因此不是把“连续几帧看见同一个候选”当作身份确认。始终需要两个通过
原有外观检查的独立样本，且聚合躯干检查仍执行，不新增低全身距离豁免。

## 两条入口统一

已映射目标在搜索期间碰到 `stale_reference` 时，也调用现有晚到候选
观察器。第一帧输出 `preferred_search_mapped_late_wait` / UID0，内部
映射仅作为假设保留；确认后输出 `preferred_search_mapped_late_reacquire`。
未知参考和明确空间矛盾不适用这条例外。

已通过这套局部确认的目标，在停车补看/搜索尚未退出期间，以已确认
局部位置接续，防止下一帧再次被旧保护锚点拒绝。持续检查外观、竞争、
几何、有效期，保护锚点继续保留，模板隔离不解除。

## 回归与局限

`tests/vision/fixtures/cap1253_coverage_recovery.json` 保存本段的采集编号、
处理编号、时间、框、转角及授权距离。回归使用合成特征复现距离，未重跑
OSNet，也不是实车轨迹仿真。

该策略回归中，CAP1264可直接建立第一帧局部确认；CAP1265、1266仍为
UID0，但不会清掉原样本；CAP1268满足第二次检查后接回，CAP1270继续。
CAP1272等灰区仍被暂缓授权，CAP1278重新观察、1279通过第二次检查。
不能宣称修改后这段每帧都会有UID，也未解决模型姿态区分的根本问题。

诊断字段 `tentative_local_confirmation_preserved` 表示保留了一份尚未
到期的合格证据，不代表本帧身份通过。未修改YOLO、小框过滤、RPM和
电机授权期限，未操作实车。
