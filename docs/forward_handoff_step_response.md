
先退出主跟随和其他电机测试程序；在平整地面留出足够直线净空，至少整组4m路程上限另加停车余量，旁边有人可立即急停。不要对着人、墙或桌子测试。核对前进方向后在交互终端输入 `STEP`。脚本不支持无确认启动。

60RPM结果及实际停车正常后，再运行：

```bash
python3 tools/test_forward_step_response.py --execute --rpms 100
```

也可用默认 `--rpms 60,100` 连续测试，但建议先单独测60。每档默认保持0.8秒，直接写 `0 → 目标RPM → 0`，不添加软件加速斜坡或修改驱动器斜坡寄存器。若在0.8秒内未达到90%，报告“未观测到”，不据此推测到达时间；确认场地和停车安全后才考虑延长 `--duration`（上限1.5秒）。测试限速固定100RPM，不使用跟随配置的180/200RPM预算。

记录左右轮各自命令起止、应答、采样时间、实测RPM和编码器角度；生成 `calibration/forward_step_response_*.json` 与CSV。分析起动时间、达到50%/90%的时间、零速指令后停稳时间和编码器路程。停车测试测的是写零目标后的响应，不等同于紧急制动能力；异常和最终清理才执行急停。驻车电流留为0A，不恢复此前驻车电流。

反馈故障、意外倒转、过速、超时或路程超限会中止并尝试急停。软件/串口保护不能替代现场急停，通信完全故障时尤其如此。编码器路程根据26cm轮径、360度/圈换算，不是独立地面位移真值；左右轮读取顺序和时间差保留在原始记录中。
