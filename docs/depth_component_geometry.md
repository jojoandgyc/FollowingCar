# 独立Depth种子/搜索区域一致性修复（2026-09-17）

## 基线与根因

运行 `run_20260917_210719_32682_2d967a45`，用户更正移动段为CAP182～448，之后站定。
该移动段旁路53次实时关联尝试仅成功1次，没有补齐原测距断档；tick耗时P95约63.9ms。
原代码在小躯干ROI里初始化面积/中心，却在扩大的搜索ROI里重新统计。真实人体填满
种子ROI时，后续同一人的更多身体进入搜索框，面积假增至约2.6～4.2倍，超过2.5保护线。
同一张真实深度图在假设零运动、只递增时间的检查中，修改前12张全都下一次失败。

## 修改

- 在相同的完整深度网格中提取连通域。种子/搜索ROI只负责筛选“哪些连通域在这里有
  足够支持”，不再裁断用于比较的面积和边界。在线网格仍为约160×120。
- 测距/三维中心仍使用躯干核心，不取整个连通域的腿部/地面中位数。种子记录核心区域
  相对该连通域边界的位置；后续按当前连通域的平移/尺度变换核心。不是固定旧像素框。
- 保留面积增长2.5倍、深度带±0.25m、核心深度散布、运动速度/预测残差及唯一候选检查。
  增加相对原始种子、经过距离尺度修正的面积上限，防止逐帧小扩张无限累积。
- 种子连通域如果横跨躯干ROI宽度4倍或高度3倍，记为 `seed_background_extent`，
  拒绝初始化，避免地板/墙面与躯干同深度连通时将整个环境当作人体。
  这是保守的旁路几何门，不改变主视觉贴边策略或正常深度测距规则。
- 候选计算最多8个有足够ROI支持的连通域；超过预算拒绝。不修改OpenCV全局线程配置。
  使用连通域包围框定位像素、一次计算分位数；耗时改善仍须正常负载验证。
- 新增 `association_diagnostics`：选择ROI、测量核心ROI、完整面积、核心有效像素、
  相对上帧/种子的面积比、三维位移、预测残差及具体拒绝原因。统计工具汇总候选拒绝原因。

未修改原PID、速度上限、180ms授权、ReID、搜索或电机输出；旁路结果仍不供控制使用。
未核验HFOV/外参的标记保留，没有升级成已标定三维跟踪。
