# CAP1362–1452：候选竞争资格修复

本次改变的是 **某候选能否竞争当前 UID**，不是删除检测框，也不是提升
ReID 模型能力。普通检测尺寸过滤保持不变，弱框仍可显示和观察。

## 生效范围

只有已有 UID 绑定的同一 raw track，才能提供正向参考：

- 参考来自上一条已接受的 detector 观测，不从本帧最低 ReID 候选自选；
- 新采集编号递增，采样间隔不超过 350ms，累计转角差不超过 5°；
- 与参考框 IoU ≥ 0.5、面积相似度 ≥ 0.6；
- 检测分数满足正式轨迹及身份入口，当前全身距离 ≤ min(0.30, mapped 阈值)；
- 当前没有身份怀疑、几何撤权或该轨迹的持久几何矛盾。

在此基础上，其他候选同时满足高度不足当前目标一半、面积不足 30%、
重叠占较小框面积不超过 2%、横向中心相隔至少画宽 15%，才不参与本 UID
的竞争。低于正式跟踪置信度时记为 `weak_small_observation`，否则记为
`uid_scale_position_conflict`。不是仅看小框或检测置信度，也不按坐姿排除。

未绑定且没有已知恢复假设的候选、明确身份矛盾、参考过期、明显转动、
人物交叉或尺度相近时，维持原竞争规则；缺少特征的可信竞争者仍产生
不确定性。不能保证从历史日志的任意失锁状态立即恢复。

## 补齐证据暂缺期间的恢复

对身份库明确标记为 `evidence_gap`、且 raw track 与最后可信目标一致的
恢复假设，允许沿用新鲜可信参考；若身份库已经通过第一帧恢复检查，
可以使用它保存的 `local_observation`。仍执行同样的 350ms、5°、重叠、
尺度、置信度及外观要求。竞争模块不能自行创建或刷新恢复观察。

这个阶段权限更少：只能排除低于正式跟踪置信度门槛（当前 0.50）、
面积不超过图像 2%、高度不超过图像 25% 的小框；还要同时满足前述
相对大小、无重叠和横向分离条件。可信度较高的小人物仍参与竞争。
明确外观冲突、躯干冲突、几何撤权、原始轨迹改变、已绑定其他 UID
均不能使用这条例外。

通过竞争不是确认身份：第一张合格恢复图像仍输出 UID0，后续新图像
还须通过原有外观/躯干、几何和两帧确认。没有延长电机授权期限，
也没有允许过期参考证明连续性。

## 权限与证据

竞争资格在本帧任何身份分配、模板写入之前一次性计算。保留原始候选数
及检测索引供身份库核验，另记合格候选数、排除原因和参考 CAP。
被排除候选自身的竞争结果始终为失败，不能借此取得 UID 或写入模板。

已通过逐帧身份复核但仍处于模板隔离期的目标，可以提供新鲜连续参考；
这不解除模板隔离。质量、外观、躯干、几何、接回确认及电机授权仍独立检查。

日志增加 `identity_competition_eligibility`；身份观测里的
`identity_competition` 增加 `qualified_candidate_count`、
`excluded_competitors`、`eligibility_reference_cap`、`competition_eligible`。
另记录 `eligibility_reference_kind` 区分可信身份参考和待复核观察。
低置信度小框标为 `observation_only`；身份库在普通跟踪及搜索两条路径
核对本帧 UID、检测索引、原始候选数后，直接返回
`weak_small_observation_only` / UID0，不建库、不写模板、不清理其他
轨迹的恢复计数。原始检测仍保留，未上调全局最小尺寸或 ReID 阈值。

## 验证边界

`tests/vision/test_cap1410_competition_eligibility.py` 使用 CAP1410 实际框、
距离及构造的新鲜前序参考，验证原竞争失败而新资格判断通过；不是把真实
CAP1410 的过期参考替换后宣称整段回放成功。另外复用 CAP1254 的真实接续
测试数据，确认竞争证据进入身份复核后能接续 UID，同时不解除模板隔离。

继续验证近尺寸竞争者、遮挡、缺失特征、过期参考、身份矛盾、仅检测旁路、
小尺寸正确目标和禁止错误候选写库。未运行相机、NPU 或电机；实车需比较
弱候选引发的失锁次数，并同时观察错误人物接回，不能只追求 UID 输出率。

新增 `tests/vision/test_weak_competitor_recovery.py` 覆盖暂缺恢复与明确
身份矛盾的区分、绝对尺寸和分数边界、无权更新其他候选状态、失效证明。
两帧恢复集成测试使用 CAP1254 测试库中的外观/框数据，构造背景候选与
首个恢复样本时间；不能将该结果描述为原实车日志的完整回放。
