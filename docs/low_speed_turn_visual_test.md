# 4/6RPM、1000ms、5A驻车3秒：单人静止视觉转向测试

新入口 `tools/test_low_speed_turn.py`，复用已有停车试验的 `ParkingSession`、
电机模式检查、正反符号映射、端口互斥、NORMAL写入、电流回读与异常清理。
旧工具为 `tools/imu_encoder_trace.py`、`tools/test_encoder_turn_mapping.py`；
它们默认的零速/急停、IMU脉冲标定不直接等于本次5A驻车试验。
不修改跟随控制器、PID、控制模式、加减速寄存器或永久参数。

## 已确认方案

- 只准备，等待用户明确说开始；不以准备脚本代替现场就绪确认。
- 默认四轮：左4、右4、左6、右6RPM；每个值指**单轮绝对转速**，对应轮差8、12RPM。
- 清0A并回读，零速观察350ms且确认轮子稳定后，固定下发原地目标1000ms。
  不等待达到目标RPM，不叠加软件P/启动增强；因此能记录真实建立迟滞。
- 到期设置5A并回读，执行双轮NORMAL；从双轮NORMAL完成算起保持3000ms，期间不发零速覆盖驻车。
- 清0A、回读、发送0RPM，额外观察至少350ms并确认稳定，才接续下一轮。
  固定这次视觉判定窗口，零速保持中再等至多500ms收齐异步视觉结果，
  然后再次核对新鲜双轮静止；不会移动窗口追着处理延迟跑，也不会放宽稳定门槛。
  因此两次转动之间**超过**3秒，而非含通讯、释放的严格3秒。
- 每轮实际速度写入、制动准备、NORMAL、电流释放均记录单调时钟。
  1000ms是速度写入完成后的目标维持时间；设置5A/回读/双轮STOP还有通讯延迟，
  必须报告实际超时，不冒称电机恰好在1000ms时停转。停车下发超过期限150ms中止。

## 视觉记录

复用不接管电机的 `tools/rknn_camera_track_record.py`。
新增 `capture_monotonic`、图像宽高字段，与电机事件同一主机单调时钟对齐。
时间是Python接收/交付图像时刻，不是相机曝光硬件时间；仍可能含采集缓冲延迟。
原视频和原始YOLO检测保留；不以DeepSORT平滑位置或编码器轮角冒充车身转角。

测量采用66°水平视场、主点居中的针孔近似：

`bearing(x) = atan((2*x-1) * tan(66°/2))`

静止目标、近似纯旋转条件下，车身右转角约为 `bearing(x_start)-bearing(x_end)`。
它不是简单的 `66*(x_start-x_end)`；需要标定内参/畸变才能进一步提高精度。
相机相对旋转中心的平移、打滑、人体姿态变化和框抖动都会影响这个估计。
建议人在安全距离站定、单人入镜、不转身摆臂；辅助急停人员留在画面外。

分别输出：1000ms期限附近累计角、该区间平均角速度、NORMAL之后残余角、
最后静置窗口角度及抖动范围、首次连续两帧超过1°位移的可观察延迟。
这个延迟不是轮子真正起动瞬间；平均角速度包含启动迟滞，不是稳态角速度。
边界只在前后视觉样本跨度≤200ms时插值；缺采样返回不可判定，不补造数据。

## 启动（仅现场确认后）

先停止主跟随和其他电机/相机程序，确认平整、周边空旷并有物理急停。
本工具没有避障，软件无法保证掉电、通信断开、主机冻结后的停止。

在项目根目录，为每次实测创建独立目录，避免覆盖录像：

```bash
turn_test_dir=$(mktemp -d /home/topeet/Desktop/rk_car_runtime_module/calibration/turn_visual_XXXXXX)
echo "$turn_test_dir"
python3 tools/rknn_camera_track_record.py \
  --device /dev/v4l/by-id/usb-Astra_Pro_HD_Camera_Astra_Pro_HD_Camera-video-index0 \
  --width 640 --height 480 --fps 30 --fourcc YUYV --no-reid \
  --output-dir "$turn_test_dir" --name turn \
  --raw-writer-mode opencv_mjpg_avi --raw-output "$turn_test_dir/raw.avi" \
  --jsonl "$turn_test_dir/vision.jsonl"
```

保持录像进程运行，在另一个终端将 `--vision-jsonl` 指向刚才目录。
先预览（不打开硬件）：

```bash
python3 tools/test_low_speed_turn.py
```

确认安全相电流上限后，实际启动使用：

```bash
read -r -p '已核实的安全相电流上限(A): ' turn_test_safe_current
read -r -p '上面生成的录像目录绝对路径: ' turn_test_record_dir
python3 tools/test_low_speed_turn.py --execute --hold-ms 3000 \
  --rated-current-a "$turn_test_safe_current" \
  --vision-jsonl "$turn_test_record_dir/vision.jsonl" \
  --output-dir "$turn_test_record_dir"
```

仍须输入 `TURN`。默认整组自动接续，不自动重新对准目标；任一轮未稳就终止。
完成后单独Ctrl-C退出录像，等待其保存结束。

电机故障/超温/超安全电流、实际轮速超过16RPM、逆向反馈、通讯/编码器异常、
单轮累计路程>0.30m、轮次超7秒、目标消失/多人体/跳变/接近边缘/视觉陈旧均终止。
最后画面缺采样或仍明显移动也停止后续测试；不会为了完成四轮放宽条件。
异常、Ctrl-C、SIGTERM尝试双轮急停、清0A、保存部分原始数据；清理失败须物理急停。
