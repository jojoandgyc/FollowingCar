# CAP1198～1304：贴边接续、执行响应与制动证据

仅修改软件策略和无硬件回归；不操作摄像头、NPU、串口或电机。
依据 `run_20260924_211713_45516_e79b6587`，并纳入用户提供的
“电机至少约500ms才能建立目标速度”。该时间是观察起点，不是已标定的上限或制动能力。

## 1. 有界贴边接续

原正常/弱质量分档不作全局放宽。首次建库、搜索接回和模板隔离不走新入口。
只允许已绑定、非搜索、非隔离、无既有矛盾的目标，在唯一候选、当前身份竞争与
几何通过、授权全身距离不大于0.15、近期局部无可靠冲突时接续。

新入口只识别 `edge_touch>2` 这一单一质量原因：上/下裁切加一侧裁切，
宽至少120px且不少于图宽18%、高至少图高85%、宽高比0.25～1.2。
这是身体覆盖的几何代理，不是姿态识别，不允许仅凭低ReID距离接回新人物。

接续期不超过最后一次普通强观测之后500ms，不更新这个起点、不写任何身份模板。
身份排除、几何冲突、多人竞争、残片、陌生轨迹仍拒绝。
使用 `mapped_crop_continuation` 记录来源CAP和剩余时间，原始弱质量原因单独保留。
此UID可以通过正常深度几何接口，但仍必须获得新鲜、可信的物理深度授权；
保留身份状态绝不续期旧距离。

这不是保证本段25个弱帧全部正常通过：长期裁切、证据不足或超过期限仍降级。
目的在于减少瞬时边界变化造成的正常跟随/原地转向切换。

## 2. 电机响应时序

正常速度指令立即照常执行，不新增500ms停车等待。
差速辅助和被动“响应不足”诊断改为：连续成功下发同方向近似轮差至少500ms，
然后才评估反馈不足；辅助仍要求两次独立、新鲜、下发后的编码器反馈。
零指令、UID变化、写入历史断裂都不能继承旧的连续执行时间。

普通横向授权仍有效、仅辅助所用视觉稍超过250ms（不超过350ms）时暂停辅助，
不永久关闭已开始的辅助事件；新的合格图像只能在原350ms事件截止前恢复。
近距离、真实制动、失权、过期反馈、换向保护不放宽。

本轮维持双轮差20RPM上限，不用增大差速掩盖加速延迟；保持前进均值，不恢复
“内轮实测+2RPM”共同降速策略。当前已满单轮10RPM时辅助仍无额外幅度，
日志会如实显示零增量。用户提供的500ms不用于改写物理深度期限或刹车延迟。
旧100ms比较测试显式保留旧假设，新增测试覆盖生产默认500ms及真实写入接口。

## 3. 边界旋转不确定性

原始接近速度窗口仍只接收旋转不确定度不超过0.25m/s的样本。
对于0.25～0.35m/s的边界退出，仅当其他几何、深度、身份和轮速检查已通过，
且原可信速度证据不超过180ms时：

- 清空原始回归窗口，不插入本次样本，禁止跨未经补偿的转动直接差分。
- 保留旧PI运动记忆，时间起点不更新；增加不确定性扣减，端点反证也按0.35m/s处理。
- 只能降速或保持既有批准上限，不能用旧记忆提速、恢复过期授权。
- 重复边界失败不能滚动续期；超过180ms、较大旋转不确定性、反馈故障或危险仍退出。
- 新的可用几何从第一张样本重新建回归；两张合格数据恢复原始运动证据。

实测距离明显缩短时仍优先刹车，CAP1271之后真实接近不能被当成“全部错误停车”。

## 回归范围

真实CAP1202框的身份模块与DeepSortTracker→深度几何接口；合成特征仅验证策略，
不声称验证了ReID模型精度。另覆盖无模板污染、不可滚动的500ms接续、搜索/隔离/
多人/错人/残片拒绝、500ms电机观察、辅助原截止时间、运动记忆180ms退出、真实接近
刹停。历史日志不能证明修改后的车体轨迹，下一轮应比较零指令占比、连续执行时的
实测轮差和回中过冲。
