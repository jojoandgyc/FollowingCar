## 实施规则

1. 同一已接受物理Depth输入，维护独立的接近速度与匹配人速窗口。
   人速仍使用原始Depth+同区间编码器积分；但FF的±10°方位限制、预热、模型资格拒绝
   不再清空制动窗口。不能把“人速未知”当成“目标停止”或“目标距离失效”。
2. 独立制动在新鲜、同UID、深度已接受且编码器可信时更新。
   基于原始检测框方位、RGB/Depth时间差及原始/滤波角速度的最大幅值，计算转动Z贡献的
   正上界，从原始距离变化中扣除，得到偏保守的接近速度。不是放宽人速模型。
   保留15°/s最大角速度、0.25m/s转动项上界；独立几何方位最多45°，补入图像年龄造成的
   方位不确定性。没有原始检测框时仅允许原低转动<=5°/s路径。
   这是短窗运动近似，不是精确世界速度或安全认证。
3. 同样本重复读取可以复用该样本结果，不追加样本、不续期。真实身份切换/危险、
   深度过期、异常跳变、不可信反馈、过大转动仍重建或保护。普通短缺测不自动抹掉
   尚未过期的历史，下一张新鲜样本仍须独立通过验证。
4. 无匹配时，合格独立制动窗口允许现有60RPM距离追赶预算；距离误差斜坡、制动包络、
   正常加速、执行限幅仍有效。这不是60RPM最低速度，近距不强制前进。
5. 编码器反馈<=150ms：用实测平均前进轮速做保守回退。
   150～300ms：若旧反馈本身可信且数值合格，使用
   `min(总上限, max(最后PID请求, 旧实测轮速 + 加速上界×反馈年龄))`。
   加速上界取至少240RPM/s及配置上升斜率中的较大值。不得将负轮速或反转当作前进。
   更旧/无反馈/异常值仍按原最大上界保守处理。此旧反馈不能生成新速度测量，
   更不能刷新深度期限。加速上界也是待实测假设，应核对轮速超调。
6. 人速补偿可关闭；估计仍记日志，但不影响输出、不启用旧FF桥接及其授权期限。
   默认仍启用，便于分开评估本次解耦和关闭前馈的效果。倒车逻辑不变。


```sh

```

也可修改INI `[distance_pid] approach_matching_enable`，但不必同时修改其他参数。

纯距离比例参考仍可能存在行走稳态误差，A/B是验证，不承诺该模式必然更优。
