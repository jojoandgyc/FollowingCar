# 制动证据切换造成的高—低—高转速修复

## 范围与证据

本轮只修距离 PI 的制动证据接续与恢复，不修改 P/I、180RPM起步请求、
200RPM总上限、设定距离、ReID、搜索、深度过滤或电机控制器参数。
保留物理深度授权250ms、新PI样本最大年龄180ms，以及身份/危险撤销。

旧13:45日志的 CAP330–332 批准84→0→78RPM，与 CAP435–443 的
60→16→26→34→98RPM，是用户要求优先解决的现象；它们不全是同一种降速原因。

本轮检查到更新的 `run_20260921_142326_19425_d4b8fc3c`：

- CAP41：深度样本7577.485577503，检测框采集7577.28697246，框龄约199ms；
  原始角速度9.7632°/s。深度已被接受，但制动窗口被几何门槛清空，PI输出0。
- CAP137：框龄约233ms，原始角速度−7.8375°/s，触发相同拒绝。
- CAP66：角速度约61.8°/s。这仍属于必须保护的情况，不能为消除掉速而直接放行。

原制动几何函数在角速度超过5°/s时，将可用框龄突然从250ms缩至180ms。
这是“已有新深度但制动证据失效”的独立来源，不是电机执行了180RPM。

## 实现

1. 仅距离PI制动估计可使用已经通过测距检查的250ms检测框。
   年龄仍增加预测角度及旋转不确定性；最大35°/s、45°投影角、0.25m/s
   转动影响上限不变。身份不符、无可靠几何、超时、坏反馈仍拒绝。
   旧approach路径继续使用180ms转动几何门槛。没有把旧框或预测当新深度。
2. 合格几何下的短暂预热允许沿用现有有界运动记忆，不再额外要求距离误差>30cm。
   原始与滤波距离都必须在保持带外；新原始深度接近趋势可立即收紧制动。
   原350ms记忆上限不变，不刷新来源时间、不加速、不恢复已撤销的旧授权。
3. 确实失去制动证据时仍降低上限；证据恢复后的提速按当前最终批准值接续。
   使用现有正常上升率（未配置正值时240RPM/s），单次只计算新鲜更新间隔，
   最多180ms；授权已经失效/撤销时不借用空档加速时间，起点不高于实测轮速。
   没有固定低速阶段、5RPM重新起步或重新计时的等待。
   初次起步和连续可靠跟踪不增加第二套软件爬坡；更紧制动仍立即生效。
4. 增加 `distance_brake_transition`、`geometry_limit_ms`、
   `brake_recovery_limited`、`brake_recovery_anchor_rpm`。
   记录制动来源、上次输出、新请求、变化幅度、限制原因、记忆来源时间，便于
   区分必要制动、证据切换和执行层损失。日志不会读取额外串口或驱动电机。

## 下一轮验收

保持本轮参数与路线，标注明确的移动/站定CAP区间：

- 合格ROI年龄180–250ms、转动影响在预算内：仅因旧180ms门槛清空制动证据为0次。
- 制动证据恢复的增速符合记录的批准起点和上升预算；无单帧跳回旧高请求。
- 分开统计0.3秒内下降>10RPM后、0.3秒内再上升>10RPM的事件数/10秒，
  对照日志逐个归因；同场景争取降低50%，不把真实停车算作应取消的异常。
- 同时统计批准→实际下发损失、零轮速时间占比、移动距离平均绝对误差及最大距离；
  不能仅通过抑制恢复提速使“速度波动”好看而让跟随更慢。
- 站定后的最小距离、收敛时间、反向轮速不能恶化。保留现场急停与监督。
