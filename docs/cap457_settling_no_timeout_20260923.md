# CAP457 后停稳超时锁存移除

按用户要求删除普通驻车释放后 2 秒未停稳即锁存
`post_release_settle_timeout`、要求重启的条件及其常量。

仅等待时间变长不再产生永久故障；普通停车继续收集新鲜双轮反馈，
释放仍经过现有反馈、图像及运动资格检查，不因时间流逝授权运动。
停稳反馈缺失、过期、不可信或轮速仍不满足要求时，停稳释放入口继续等待。
原有合格运动交接及反转保护不变，不自动重放停车前指令。

电流清零/读回失败、FREE 下发失败、清电流期间危险或授权变化的
故障保护保留，故障仍不能被旧零速或旧 NORMAL 覆盖。
未修改当前 0A 配置、EMERGENCY → NORMAL 顺序或 500ms 保持时间。

无硬件回归覆盖：近距离及搜索接回两条入口、0A/5A、超过 2 秒/30 秒
后仍可凭两次新鲜停稳反馈与新图像通过释放检查；单次安静反馈、旧图像、
坏反馈不解锁；FREE 通信故障仍锁存并保持 EMERGENCY。
本次不操作实车。已运行的旧进程不会热更新，需正常重启跟随程序加载修改。

验证：电机测试 746 passed；全量 4591 passed、3 项既有失败
（目标距离配置断言及两项搜索方向测试）；`git diff --check` 通过。
