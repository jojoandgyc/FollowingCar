# CAP182–352：驻车电流交接与原地纠偏

## 问题与边界

分析基线：`run_20260922_162355_19003_20d218f9`。该片段约8.917秒，
转向建立增强未触发，最大下发轮差20RPM；不能把过冲归因于新增加的前进增强。
零指令时间约5.889秒（66.04%，含合理驻车），非零轮速命令换向3次。
CAP190驻车释放后长时间零速等待；原实现只在启动时写5A，退出时未写0A。
CAP301和323从图像采集到实际NORMAL分别约327ms、220ms；贴边降级还丢失了减速位置证据。

本次按用户补充的控制器行为处理电流切换。不修改ReID、深度过滤、授权期限、
正常前进转向增益、正常轮差及临时增强上限。不操作实车。

## 实现

1. **驻车电流生命周期**
   - NORMAL前恢复配置驻车电流（当前5A），双轮寄存器读回确认后才发送NORMAL。
   - 允许退出驻车后，先把双轮驻车电流写为0A并读回，再进入速度模式，
     包括反转保护要求的0RPM。不让5A驻车和零速闭环混在一起。
   - 保留现有100ms驻车下限、停车后新图像和反馈检查；显式驻车保持期间的零速续发仍被抑制。
   - 原地反向纠偏继续经过真实轮速反转保护；正常、已安全同向的前进交接不额外等待。
     不强制在5A保持下等到反馈完全静止才清电流，以免控制器驻车抖动形成新死锁。
   - 普通状态切换只进行易失写入，不每50ms重写，不反复保存到控制器。
     启动原有保存策略不变，启动驻车不会被兼容的arm接口立即撤掉。
   - 写入、读回失败或非有限值触发急停并禁止随后非零写入；部分写入标记为不确定，后续重试。
   - 跟随执行器将寄存器耗时计入授权年龄。切换后重新检查授权、UID、横向状态和危险，
     不能把寄存器操作时间变成旧指令的额外寿命。

2. **贴边减速证据与运动权限分离**
   - 增加独立`braking_observation`，不填回`depth_observation`。
   - 仅当前活动UID、唯一精确匹配的原始检测、可信映射和新鲜同帧元数据可参与。
     覆盖`mapped_low_quality`、`mapped_weak_observed`；拒绝身份冲突、竞争失败、
     排除轨迹、待确认候选及几何失败。
   - 按真实采集时间检查短窗位置/面积连续，只提供向中心移动的速度用于减速。
     不改控制方向/位置，不提供向外增强，不授权前进、不更新身份库。

3. **原地纠偏单独降速和提前减速**
   - `near_distance_rotation_only_max_rpm`从10降至7（试验值）。
   - 仅`_parked_recenter_pid`的编码器预测响应预算至少100ms，
     视觉残余响应预算至少250ms，图像年龄加响应的上限从250ms放到500ms。
   - 500ms是预测计算上限，不是视觉证据或电机授权有效期；旧证据不能续期。
   - 正常前进控制器仍使用原配置。上述响应预算是待实测校准的保守假设，
     并非已经测出的恒定制动时间，也不是新增固定驻车等待。

4. **异常反馈与提前反打**
   - 原始角速度超过35度/秒时，必须连续两个同向编码器样本才进入预测制动；
     单点尖峰只保留诊断，不把2RPM起转直接升级成整车驻车。
   - 近中心且新鲜图像明确向中心移动，或目标基本停住而仍有连续残余角速度时，
     允许最多2.5RPM的短时反向轮差，用于提前消除残余旋转；反打不授予前进、
     不更新身份，也不改变正常差速上限。后者覆盖CAP166目标停住、下一帧才发现过冲的窗口。
   - 反打只在预测制动、反馈可信且角速度达到8度/秒时出现；配置为0即可恢复纯滑行制动。
   - 贴边映射目标可以解除普通原地驻车进入受限横向恢复；仍不能解除身份、深度或纵向授权。

## 下一轮验收

| 指标 | 核对标准 |
|---|---|
| 驻车进入/退出电流 | 每次普通进入确认5A、退出确认0A；重复续发不重复写寄存器 |
| 电流切换耗时 | 统计`parking_current_transition elapsed_ms`的P50/P95；授权过期后无非零旧指令 |
| 驻车释放到有效纠偏 | 分离电流切换、真实反转等待、首条非零及实测轮差建立时间；不能再次出现数秒零速等待 |
| 首次纠偏过冲 | 按同方向纠偏段统计首次越过中心幅度、反向修正次数、进入中心后稳定时间，均应下降 |
| 贴边减速证据 | 连续映射目标可出现`braking_only:capture_rate_valid`；仍不能因此恢复前进或身份确认 |
| 不相关行为 | 正常差速前进轮差和增益不变；危险、深度过期、真实反转保护继续有效 |

不要单纯追求降低66.04%的零指令比例：正常居中驻车本身需要零运动。
本次尤其要比较CAP138式单点高反馈的停车次数，以及`predictive_countersteer`
实际持续时间；若反打后首次越过中心幅度增加，应立即将该配置归零回退。
控制参数与电流交接同时变化，不能把改善全部归因于7RPM。
