# 速度估计反馈边界与独立 P 试验

## 修改前基线与本轮范围

运行 `run_20260916_230608_35466_9cd5b4aa`，移动 CAP92~322，站定 CAP322~419。
移动采集 12.412s，执行/控制指标尾随 180ms，分母 12.592s；目标距离 1.5m。
距离只统计已选中目标的已处理控制帧；缺失率与有效距离误差分别报告，不填补缺失值。

本轮不修改搜索、ReID、深度采样、执行器、横向 PID 或电机总上限。
此前重复观测保留修复生效：指定低置信度 duplicate 引起的重置为 0。
仍有 8 次 yaw_limit、4 次 depth_timestamp_missing 显式清空；估计器另有
3 条 ego_speed_out_of_bounds。CAP193 批准基速 52->32RPM；CAP253 附近
实际反馈 102/100RPM，均速101，越过了估计器100RPM边界。

## 方案与实施

1. 原始角速度是同次双轮反馈的推导值，滤波角速度是最近三次的中位数，
   二者时间含义不同。没有修改反馈线程、旋转方向或安全使用的最大角速度。
   对异号值不直接挑选“有利于前进”的值，也不简单忽略滤波值。
2. 仅同UID的可靠原始框、新鲜可信Depth、可信编码器、编码器-Depth错位<=50ms，
   且 raw/used 距离都>目标+0.20m 时，尝试有界补偿。
   对两个方向的最大测得角速度（<=15°/s）计算投影方位范围，保留既有
   RGB/Depth对齐期限、方位<=10°和几何有效检查。使用
   `|omega|max * Z * |tan(bearing)|max` 作为正向补偿上界，从速度估计中扣除。
   仅该上界<=0.04m/s时可用（0.60m轮周约4RPM），以少量低估换取连续性。
   假设真实角速度在测得幅度范围内；它不是完成实车校准的运动模型。
   较大不确定性、近距、过期、无框、错位仍退出/重建，不延长任何授权。
3. 将运行控制器的测量容差设为 `min(105, max(100, forward_max_rpm))`。
   只处理约101RPM的边界反馈；不截断实际轮速，不把101伪装成100。
   估计器独立默认100不变，正常200RPM配置下容差105；超过105仍拒绝。
   匹配基速80、总输出200、目标最大可行速度、跳变及其他安全限制不变。
   重复观测保留/前馈桥接的轮速检查使用同一测量上限；恢复限速分支未放宽。
4. 纵向P默认仍24RPM/m。增加专用 `FOLLOW_DISTANCE_P_TRIAL=24|27`，
   只覆盖INI中的纵向P，非法值启动时报错；I、D、横向P、限速均不修改。
   普通 `DISTANCE_PID_KP_RPM_PER_M` 会被INI覆盖，不能用它做可靠A/B。

## 日志与指标

- `longitudinal_feedback_config`：实际P、测量上限、补偿不确定性、时差和Depth期限。
- `longitudinal_feedback_audit`：物理样本/UID/CAP、raw/filtered yaw、时间差、
  补偿值、双轮反馈；`yaw_disagreement_bounded` 表示窄范围保守补偿，
  `yaw_disagreement_rejected` 表示仍被拒绝。审计不等于电机授权。
- 指标脚本新增 `feedback_config`、`feedback_audited_distinct_samples`、
  `feedback_compensation_distinct_samples`（按UID/物理样本去重），以及
  `estimator_status_records`。旧日志缺少审计返回空字典，不能解释为功能已验证。
- 仍统计 `motion_reset_reasons`、无基速比例、批准速度200ms内下降>10RPM、
  深度间隙、零指令驻留；零指令不是实际物理停车。
