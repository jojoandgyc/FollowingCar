# 恢复 5A，保留 EMERGENCY

当前主配置为 `parking_current_a = 5.0`、`stop_mode = emergency`。
普通近距离/搜索接回/轮速交接停车显式启用电流准备：恢复双轮 5A 并读回确认，
再执行一次 EMERGENCY，不接 NORMAL。已确认的同值电流可复用缓存。

500ms 普通保持期仍从 STOP 完成计时，之后清双轮 0A、读回并执行 FREE，
按既有新证据检查恢复；下次普通停车再次恢复 5A。危险急停和故障急停
仍直接发送 EMERGENCY，不等待驻车电流设置。

启动也尊重 emergency 配置：先急停并清除旧电流，随后设置 5A、执行 EMERGENCY，
不再走旧 NORMAL 预锁相路径。首次进入速度模式仍清 0A。
电流设置失败时尝试 EMERGENCY，不标记成功保持，不授权运动。

本轮未操作实车，重启程序后生效。5A 是寄存器设定，不代表 EMERGENCY 下
必定输出 5A 实际相电流，也不能仅凭软件修改保证制动时间改善。
