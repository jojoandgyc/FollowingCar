# 小幅瞬时停止证据与常量前进补偿试验

## 为什么可以试常量，但不能当成标定

同一代码、相近走速/路线，唯一改变补偿常量，能检验增加指令是否改善距离误差。
它不能区分轮周/RPM换算偏小、深度偏差、估计清空或其他掉速；不能证明模型正确。
若模型是比例误差，固定常量也无法适应所有走速。因此不改轮周0.60m、不伪造人速。

修改前 `run_20260916_232550_36789_b5976229`，移动CAP159~410约13.553s，
控制/执行统计另尾随180ms（分母13.733s），P24、目标1.5m。
MAE0.469m、最大2.276m、短降>10RPM为10.92次/10秒、无基速23.01%、零指令6.04%。
CAP345：瞬时目标速度-0.021m/s，162ms窗口+0.186m/s，却按stop_evidence清空。

## 修改范围

### 一次小幅矛盾先降速，不立刻清空

仅新鲜可信的独立物理Depth，已有正向匹配、有效短窗>=4点且跨度>=100ms、
短窗速度>=0.10m/s、距离>目标+0.30m、距离预计400ms内不进入近距带，且
相邻样本间隔<=100ms、瞬时速度在[-0.05,0.03]m/s时，允许一次
`stop_suspect_bounded`。此帧按照80RPM/s降低原匹配输出，不加速、不清除短窗。

第二次弱证据仍立即清空。两次新鲜正向样本后才重新获得一次容错资格，避免
“弱-强-弱”交替无限保持。重复帧不累计次数、不过期续命；深度跳变、身份变化、
大负速度、近距离/TTC危险、转动/反馈越界仍走原保护。
确实停止但仅产生小负值时，可能比原来多一个可信样本的减速过程；不是零延迟保证。

### 独立常量试验（默认关闭）

`FOLLOW_MATCHING_BIAS_TRIAL=0|5|10`：单位RPM，非法输入拒绝启动。
经配置加载映射到 `DISTANCE_MATCHING_TEST_BIAS_RPM`，默认0；不写回INI。

- 只加到合格匹配基速的控制请求，不改速度估计器、历史模板、速度原始值或时间戳。
- 仅正常ready/ready_capped、正向瞬时速度>0.03m/s、短窗速度>0.10m/s、
  至少3个窗口点/60ms、`bounded_far_positive`路径可加。
- 目标+0.50m及更远时增加设定常量，目标+0.20~0.50m之间逐渐降到0；
  目标1.5m时即2.0m以上全量、1.7~2.0m线性退出。
- 预热、桥接、疑似停止、停止证据都不新增补偿。所有原有深度/身份/危险资格仍检查。
- 不突破匹配80RPM和总200RPM限制，下游PID斜率/限幅仍可减少实际增量。
- 旧授权可按原有期限保持/衰减，但重复帧不能再加一次常量或更新PID；
  未加常量的估计仍保存在前馈桥接参考中，不把试验偏置传播为新测量。
- 日志 `longitudinal_bias_trial` 区分 measured_base / applied_bias / result_base；
  同样本相同数值不反复打印。实际净增加多少应看批准轮速和编码器，不只看bias字段。

本轮P默认24、匹配80、总200、物理Depth180ms、搜索/ReID/横向/电机执行器不改。

## 速度换算只读审计

新增 `tools/encoder_scale_audit.py`，无摄像头/串口/电机依赖，不写标定。
用CAP真实时间与实测反馈积分轮转数，覆盖缺失或间隙>150ms时明确拒绝外推。
独立实测位移必须覆盖所给CAP精确区间，不能用更短Depth子区间的距离替代。

```sh
# 仅在确知目标/采样表面静止时做深度交叉检查
python3 tools/encoder_scale_audit.py run_request_0428_modular_logs/run_20260916_232550_36789_b5976229 --cap-start 412 --cap-end 435 --fixed-target
```

现有素材该Depth子区间1.246s，深度缩短0.4148m、按0.60m轮周的编码器积分0.2890m，
比值1.435。这只是交叉检查，不说明轮周应改为0.861m。
较大CAP410~438的完整区间在端点附近反馈覆盖不足，工具拒绝外推；不能自动填空。

进一步实测应在正式地面低速直线运行、固定测距表面，独立测车体真实位移，
将精确CAP区间和实测米数传入 `--measured-travel-m`。重复不同低速；排查滑移、
轮速寄存器比例、深度尺度和采样漂移。输出的推算轮周只是建议值，仍不自动应用。
本轮未执行该实车标定，也未改变0.60m配置。
