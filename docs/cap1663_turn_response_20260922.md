# 转向建立补偿与中心余速交接试验

## 问题与范围

依据运行 `run_20260922_142417_13432_8a4ea73d`，CAP1660～1673 内没有双轮零速。
14:25:46.823 开始下发左转 32/52 RPM，反馈却仍为右转；47.245 才首次记录
44/53 RPM 的左转反馈，日志响应间隔约 422ms。CAP1663 图像到首次下发另有约
153ms，两者不是同一段延迟，不可相互替代，也不可将指令旁的缓存反馈当作即时响应。

本次只调整正常、可信差速前进的执行组合，不增加全程横向 P，不改纵向 PI、
ReID、深度过滤、250ms 深度授权、搜索 RPM、66° 水平视场。
不直接操作实车；离线测试证明分支行为，不证明真实响应时间改善。

## 实施方案

1. 方向和正常修正仍由现有图像位置控制给出，正常总轮差上限仍为 30 RPM。
2. 目标偏离至少 6°、图像/身份可靠、深度仍授权前进、反馈年龄不超过 100ms，
   且没有预测减速、受限接回、近距离原地转向或驻车时，允许一次转向建立增强。
   单轮修正为正常值的最多 1.4 倍，最高 20 RPM，即总轮差最多 40 RPM。
   保持原纵向平均值；达到总轮速上限时只降低平均值，不靠提高平均车速增强转向。
3. 单次计算窗口最多 350ms。新视觉帧不重启同方向窗口；不是锁定执行 350ms，
   每次下发仍重查当前深度、横向授权、UID、驻车和危险。到期在下一次执行计算
   撤掉增强，电机实际响应还包含周期和通讯延迟，不能宣称物理轮速瞬时回落。
4. 实测同向轮差达到 `max(6, min(10, abs(正常单轮修正))) RPM`，第一条反馈
   就不再增强；连续两条不同时间戳的反馈锁定本轮完成，避免噪声反复重启。
   反馈过期、目标证据失效、快速接近中心、快循环进入预测减速也提前结束增强。
   撤掉的仅是额外修正，正常纠偏仍保留。中心归零后须有新视觉帧才可再次启动。
5. 不为增强制造新的车轮反转：两轮实测均非负、前进基速大于正常修正才允许；
   增强不超过基速。已有真实反转保护、低速弧线交接继续生效。
6. 目标在中心附近（误差不超过 5°）、转向命令已为零、两轮仍向前且实际轮差
   至少 6 RPM 时，前进平均请求暂限为 `min(原请求, 较慢轮实测+2 RPM)`。
   示例：86/86 请求、47/35 实测，变为 37/37，而非继续共同加速。
   此限制不新增 NORMAL 或反向冲击，也不提升原来的制动请求。
   原有合格中心驻车仍执行 5A、至少 100ms；停车后的新图像和停稳检查不变。

视觉入口显式传递增强资格和角度误差；横向快循环的最新减速结果另有否决权。
进入最终电机写入前再次核对意图及减速策略是否被替换。

## 下轮实车验证

使用同路线、相近前进速度，分别记录向左和向右纠偏，标注目标移动与站定 CAP。
先在空旷环境低速验证，再评估正常跟随；不以软件最大 RPM 代表已验证的实车能力。

| 指标 | 当前证据/口径 | 首轮试验目标 |
|---|---|---|
| 首次请求到首条同向实测轮差 | 本片段约 422ms；按反馈真实采样时间统计 | 相近场景争取 ≤300ms |
| 同向轮差稳定建立 | 连续两条独立反馈达到上述门槛 | 单独统计中位数/P95，与改前比较 |
| 增强撤销 | 首条建立/接近中心/减速否决后的执行记录 | 不再下发额外增强；记录执行延迟 |
| 请求轮差/实下发轮差 | 正常≤30，增强≤40 RPM | 不被新增路径整车清零 |
| 零轮速时间 | CAP1660～1673 原片段为0 | 同类有效授权段不新增零速 |
| 首次越过中心最大角度、反向修正次数 | 必须含后续停车段，不能只截取建立段 | 不比同场景基线恶化 |
| 中心余速阶段共同加速 | 原片段64→94 RPM且仍有反向余速 | 符合限制条件时不再共同加速 |

300ms 是试验目标，不是保证。若建立变快但过冲明显增加，应先关闭本试验，
检查撤销时序和实际停车响应，而不是继续提高短时上限。
