# 人速与制动共用原始深度时间窗（2026-09-17）

## 问题与范围

基线：`run_20260917_223601_38807_01107c3f`，移动 CAP78～338，338后站定。
移动186条PID记录中46条无匹配基速：23次warming_up、17次yaw_limit、3次bearing_limit、
2次interval_too_short、1次transient_bridge。这些是PID记录数，不等于46次独立故障。
无匹配不等于没有距离，也不等于人已经停止。

CAP235：物理新深度间隔71.4ms，raw=2.047m、used=2.084m，轮速77/74RPM。
制动已具有3个原始样本、120.6ms短窗，接近速度约0.634m/s；匹配链却因
`compensated_gap_unverified`重新预热，基速变零，批准输出88→42RPM。
该次`normal_live_continuation=True`，并非恢复限速再次卡住。

本次只改变`distance_approach_enable=True`的纵向估计接入，不动ReID、搜索、横向决策、
深度关联权限、速度上限、授权180ms期限，也不执行实车动作。旧PID模式继续原估计路径。

## 实施

1. 同UID、已经通过原始深度/反馈/几何检查的样本进入唯一短窗，使用物理采集时间。
   原始Z变化扣除区间转动贡献后拟合相对速度；在同一时间段积分实测轮速，再拟合目标速度。
   不是把窗口最后一刻的轮速直接加到整个区间的深度变化上。
2. 人速匹配与接近制动共用样本数、起止时间和相对速度；滤波距离只用于距离误差。
   有效零人速仍保留接近速度；预热/未知不是目标静止证据。
   近距或快速接近仍可用即时观测降低匹配，不能因平滑而延迟必要减速。
3. 普通短时测量尝试失败只记录期间角速度范围，不添加样本、不续期。
   下一张深度独立通过检查后，评估区间转动误差界；不再仅因角速度变化超过3°/s重建。
   采用允许的±10°方位带与角速度跨度估计误差，超过0.04m/s仍重建。
   低角速度且缺失补偿贡献可约束在0.02m/s内时，允许数值零与显式零接续，
   避免仅因`None/0`模式切换清空；这只是短窗近轴近似，不是完整世界坐标跟踪。
4. 有补偿仍最多15°/s，无补偿最多5°/s；超限、身份变化、危险、深度过期、异常跳变
   和不可靠反馈继续保护。物理间隔超过180ms不跨段差分。
5. 同一可信样本再次被控制流程读取，可以复用该样本已经算出的制动速度，
   不退回编码器保守参考；不追加样本、不刷新证据时间、不额外授权加速。

轮速积分用相邻已校验反馈的梯形近似，没有新增串口查询或后台线程。
编码器比例、转动模型与制动减速度仍需独立实测；本次不声称所有17次yaw_limit都已解决。
直接删除角速度保护可能把转弯造成的距离变化当成人速，不能以此减少统计数字。
