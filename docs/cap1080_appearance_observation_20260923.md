# CAP1080–1114 外观观察与跨侧接续试验

## 范围与阈值

针对 `run_20260923_124515_8127_e3643a84`，不改变 YOLO、RPM、PID 或运动授权时限。

运行配置的 `partial_match_threshold` 从 0.34 调到 **0.45**。这里明确分成两级：

- 可靠近期躯干距离 ≤0.34：可参与已有身份确认链，仍需几何、竞争、时效等检查。
- 0.34～0.45：`partial_evidence_tentative`，只保留待核验观察；需要辅助证据的接回不能因此输出 UID、授权运动或写模板。
- >0.45：仍是躯干冲突。

确认上限为 `min(partial_match_threshold, partial_confirm_threshold)`，后者默认 0.34。聚合躯干证据同样遵守该上限。不是把所有原 0.34 身份门槛直接放宽成 0.45；此前错误人物的 0.396 不能单凭新阈值获得身份。

## 候选轨迹与可信记录分离

`CandidateObservationMemory` 只存短期未确认轨迹，不更新可信方向锚点，也不写身份库。

候选必须有新鲜采集、同一 raw track、可用车体角度、合格外观及竞争结果，且局部几何连续。最大相邻间隔沿用接回配置（本次 0.35 秒），总观察跨度 3 秒、最多 16 条。

候选从原搜索方向一侧连续穿过画面中心，可以保留“观察到跨侧”的事实；这不等于身份成立。只有新的躯干证据进入 ≤0.34 区间，才能进入原有多帧确认。初次就在反方向出现的人不能使用此入口；明确空间矛盾仍持久保存，局部连续不能解除。

已真正通过 partial 接回的目标，在同一短观察链上可以用新的可靠证据继续复核。该接续仍不释放模板隔离、不学习。失效、冲突、换轨、断档和重复样本不能刷新此资格。

## 模板覆盖范围：已做与未做

检测元数据新增图像尺寸。模板记忆按上/下/侧边截断情况保留有限的不同覆盖范围代表，仍只接收原学习门控批准的样本；保留原有容量、过期和隔离规则。查询命中不续期。

诊断新增查询/命中模板的覆盖类别、同覆盖类别数量和距离。覆盖相同不代表肩髋区域精确对齐，也不代表姿态相同。**本轮没有加入关键点模型或解剖学区域对齐，也没有让“不可比”成为绕过身份矛盾的理由。** 这部分改变匹配权限需要后续真实正负裁剪对照。
