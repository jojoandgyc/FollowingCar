## 2. 交接与新授权

- 同一转向上游暂时要求零时，保留等待起点、实际写零时间及换向来源。
- 不累计该零分支中的停稳样本，并清除旧放行窗口；显式停车仍完整取消等待。
- 周期发送器发现同UID新的有效前进轴已替换旧计划时，同一个I/O锁内最多重算一次。
  不先写旧计划或插入不必要的零；若持续变化、失权、换UID、危险，仍停止。
- 在反馈后、实际写入前重新检查最新轴；避免已经作废的原地转向计划创建新的换向等待。
- 新前进请求仍通过轮速保护，不能绕过真实倒车或深度期限。
- 所有非零下发共用最终反馈资格检查。即使普通停稳确认已经通过，后续安全检查耗时
  导致反馈超过150ms，或其间出现错误码、身份／期限变化，也不能继续下发。

## 3. 前进量与差速

`TurnBuildup`默认只叠加有界差速，不再按“实测内轮+2RPM”削减共同速度：
原90→42、96→48、100→58RPM的辅助输入，分别保留90、96、100RPM。
纯策略构造参数`legacy_common_accel_limit=True`只用于离线历史对照，实际运行默认关闭。

周期发送器的饱和处理也统一为先保留批准基速、再限制差速余量。
例如基速196、左转半差10、绝对上限200时，输出192／200，而非186／200。
在基速已到200时没有额外差速空间；不突破总上限，也不承诺同样轮差一定更快建立。

## 4. 反馈与制动证据诊断

- 使用原有左右串行读取，新增各自读取开始／结束时间，不增加串口读取。
  这些是读取区间，不是宣称编码器同步采样。
- 执行日志新增错误码、角速度确认状态、等待轮、同向减速与残余运动确认计数。
  原始轮速、归一轮速和位置仍保留；不把位置复位的跨界差值当运动速度。
- 制动证据明确区分框龄、角速度和转动不确定性超限，并记录旧记忆剩余期限。
- 原有250～300ms轻微框龄超限的短记忆保留已经存在，本轮补回归，未重复增加宽限。
  CAP1192式偏轴转动不确定性超过0.25m/s仍拒绝，不能无补偿地跨转动差分。
